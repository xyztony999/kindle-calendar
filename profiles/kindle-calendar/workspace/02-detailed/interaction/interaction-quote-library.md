# 交互：quote-library

- 版本：v1.0（2026-10-27）

```
┌ 一言 ──────────────────────────────┐
│ ◉ 本地语料库（内置，不联网）        │
│ ○ 在线一言（hitokoto，失败回退）    │
│ ○ 自定义文案                        │
│ ── 分类（本地库生效）──             │
│ ☑诗词 ☑文学 ☐动画 ☐漫画 ☐游戏 ☐原创 │
│ ☐网络 ☐其他 ☐影视 ☐网易云 ☐哲学 ☐抖机灵│
└────────────────────────────────────┘
```

- 默认本地语料库 + 诗词/文学；切到在线/自定义时分类区隐藏（选择保留）。
- 健康卡"一言"：本地库 → 未配置；在线 → 正常/失败。
- 文案（locale）：quote_mode 三档 + quote_types 12 分类（双语）。
