## 进入代码前需要确认

1. 确认本判定。
2. 确认范围：浏览器阅读页只覆盖 `/api/v1/dashboard.json`、`/api/v1/dashboard.env`、`/weather`、`/health`。PNG、管理端、首页机器清单保持原样。
3. 确认分流：不声明网页（含 `*/*`、curl、wget、首页 `fetch("/health")`）仍是机器原文；只有写明要网页，或 `format=html`，才出阅读页。`format=json` 一律要回机器原文。
4. 确认 env 的「原始数据」仍是 env 文本，不是 JSON。
5. 确认阅读页的语言跟随网页（含 Cookie），机器原文不看 Cookie。
6. 确认用浏览器打开设备清单阅读页，仍会计一次拉取心跳。
