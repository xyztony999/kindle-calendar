# 管理端反馈交互增量

v1.0 / 2026-10-16，继承 interaction-web-admin 与 interaction-web-chrome。

登录卡使用 48px 黑白台历图形；顶栏使用同一图形的小尺寸版本。深色使用浅色图形。

数据积木名称输入下方设置“显示样式”分组：两张可点击选择卡分别展示大号首值与整齐标签数值行。选中卡通过边框、背景与 radio 同时提示，不依赖颜色。字段复选与保存保持原逻辑。

编辑区“刷新预览”旁提供自动更新和未保存说明；加载中禁用，失败恢复重试。编辑手柄仍覆盖在预览底图上。

设备卡独立列出最近通信、连接状态、配置同步状态与设备/服务端版本；未知不能写成在线。信息说明状态来自设备主动通信，非实时探测。

退出登录纳入顶栏操作行，使用 .btn，窄屏自然换行。
