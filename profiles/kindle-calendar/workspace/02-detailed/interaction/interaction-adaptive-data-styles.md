# 数据积木适用样式交互

v1.0 / 2026-10-17。用户明确选择将样式移到画布并按页面设置。

右侧“新建数据积木”只包含名称、字段和创建按钮，显示最多6项和目录顺序说明。旧静态两张样式卡移除。新建完成后积木进入左侧我的积木，点击/拖入画布才创建独立实例。

右侧另设“当前积木外观”面板。未选中数据积木时提示先在画布选一块；选中custom时显示名称、当前样式及按字段规则计算的候选卡。卡片带名称、简短说明和推荐标记，原生radio支持键盘。全都不适用的候选不呈现，避免让用户试错；长文本组合说明为何只显示列表。

原有无覆盖block继续显示实际继承样式。不适用新规则的旧hero显示“原有样式（保留）”，不自动改写；用户明确选择新候选后才写override。“恢复原样式”移除override并重新采用定义默认。

点击与拖动区分：pointerdown先选中再移动，选择不改配置；鼠标点击/键盘Enter可选中，选中边框与aria状态一致，删除按钮不误触选择。拖入时选中新实例，删除/关闭弹窗清空选中状态。系统/文字/图片积木不显示数据样式选项。

候选卡只作结构示意，主画布保持服务端真实PNG预览。切换样式按既有700ms防抖更新，可用刷新预览立即查看；加载与失败反馈沿用。文案说明“仅当前页面中的这块积木”，同定义其他实例不受影响。

外观改变不主动移动或扩展积木边界；横排/网格尺寸不足时预览会缩字/换行/省略，可拖动调大。完成接纳到草稿，全局保存后下发；取消/Escape/遮罩撤销包含样式在内的本次会话，与上一轮事务机制一致。
