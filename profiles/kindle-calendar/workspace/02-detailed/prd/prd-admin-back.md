| 状态 | 稳定 |
| 最后更新 | 2026-10-11 |

## 0. 需求澄清（D0）

用户从网站首页进入管理端之后，页面上没有回主页的入口，只能用浏览器的返回。

对照现有页面后的结论：

| 现在的页面 | 作用 | 本次 |
|------------|------|------|
| `GET /` → `server/templates/index.html` | 网站首页（landing） | 跳转目标，页面本身不改 |
| `GET /admin` → `server/templates/admin.html` | 管理端。页顶语言条在三种版面之外，始终可见 | 在这条语言条左侧加返回链接 |
| 管理端三种版面 | 未启用、登录、已登录设置 | 三种都要看得到返回链接 |
| 阅读页页脚 | 已有「返回首页」/「Back to home」，链到 `/` | 文案与之对齐，阅读页代码不改 |
| `/admin/api/*`、PNG、机器 JSON、env | 设备和脚本在用 | 不改 |

| 维度 | 结论 |
|------|------|
| 业务术语 | 返回首页、网站首页、管理端页面 |
| 角色 | 维护者在浏览器里打开管理端。家庭用户仍在 Kindle 上看画面，本模块不给他们新菜单 |
| 匹配 | 部分匹配。首页、管理端和语言条都已存在。缺的是管理端回首页的入口 |
| 类型 | 增强。不新建业务域。业务架构不新增 L4；应用架构在管理端接入下增加子模块 P-04-03 |
| 状态 | 无状态机。点一下就离开管理端，打开网站首页 |
| 规则 | 见第 4 节。链接始终指向 `/`，不使用浏览器历史返回 |
| 集成 | 只打开已经存在的首页。不新接外部系统，不改鉴权、配置和接口阅读页分流 |

本阶段按现有页面把范围定死，不再逐项追问。确认点放在 Gate 1。未确认前不写业务代码。

### 0.1 已锁定的决策

1. 按钮放在 `server/templates/admin.html` 页顶那条语言导航里，位于语言链接左侧。这条导航在未启用、登录、设置三种版面之外，所以三种都能看见。
2. 中文文案「返回首页」，英文文案「Back to home」。与阅读页已有用词相同。文案进 `admin_ui()`，随管理端当前语言切换。
3. 点击后浏览器打开 `GET /`，也就是网站首页。不调用 `history.back()`，避免书签或刷新之后退到站外。
4. 不退出登录，不提交、不丢弃接口意义上的保存。页上未保存的修改会随离开页面留在浏览器里，和现在按浏览器返回一样。
5. 不改首页、阅读页、Kindle 拉取、PNG、机器 JSON、env，以及 `/admin/api/*`。

## 1. 背景与目标

维护者从首页点「管理端」进来之后，只能靠浏览器返回回到首页。

**为谁**：在浏览器里使用管理端的维护者。

**价值**：管理端页顶有明确入口，点一下回到网站首页。登录前、登录后、管理端未启用时都能用。

## 2. 范围

| 做 | 不做 |
|----|------|
| 在管理端页顶语言条左侧增加返回链接 | 不改网站首页的版式和文案 |
| 中文「返回首页」，英文「Back to home」 | 不改阅读页已有的返回首页 |
| 链接目标为网站首页 `/` | 不使用浏览器历史返回 |
| 未启用、登录、设置三种版面都显示 | 不把链接只放在已登录顶栏 |
| 离开时保留登录会话 | 不因此退出登录，也不因此保存配置 |
| 语言仍由现有管理端语言按钮和 Cookie 决定 | 不改口令、会话、配置存储和语言规则 |

明确不改：Kindle 拉取、分区图、时钟字形、整页图、机器 JSON、env、`/admin/api/*`、接口阅读页的浏览器/机器分流。

## 3. 角色

| 角色 | 本次操作 |
|------|----------|
| 维护者 | 在管理端页顶点「返回首页」，回到网站首页。可用原有语言按钮切换中英文 |
| 家庭用户 | 无新操作。设备上的画面、翻页和轮播不变 |
| 机器客户端 | 无新操作。`dash.sh` 与部署脚本拿到的正文与今天相同 |

## 4. 行为规则

| # | 规则 |
|---|------|
| R1 | 返回链接在 `GET /admin` 的三种版面都渲染：未启用、登录、已登录设置 |
| R2 | 可见文字：语言为中文时「返回首页」，为英文时「Back to home」 |
| R3 | `href` 为 `/`。不附加查询参数，不改语言 Cookie |
| R4 | 点击不请求 `/admin/api/*`，不清除会话 Cookie |
| R5 | 设置页有未保存修改时，不弹确认。离开后那些修改不写入配置 |
| R6 | 首页按现有规则决定语言（地址、Cookie、浏览器语言）。管理端若已切换语言并写入 Cookie，回到首页后沿用该 Cookie |

## 5. 领域对象与关系

本模块不新增持久化对象。

| 对象 | 分类 | 关系 |
|------|------|------|
| 返回链接 | 过程数据（P3，界面上的一个链接） | 出现在管理端页面上，指向网站首页 |
| 网站首页 | 关联页面 | 已有 `GET /`，本模块只引用它，不改它的内容 |
| 管理端会话 | 关联过程数据 | 已有登录会话。点返回不创建、不销毁它 |
| 台历配置 | 关联领域对象 | 已有配置。点返回不读取、不写入它 |

被引用关系：其他流程不依赖这个链接。设备拉取、预览、保存、阅读页都不读取它。

## 7. 验收

1. 打开 `/admin` 的未启用、登录、已登录三种版面，页顶都能看到返回链接。
2. 中文页面文字为「返回首页」，英文页面文字为「Back to home」。
3. 点击后地址变为网站首页 `/`，能看到首页页头。
4. 已登录时再进入 `/admin`，仍是已登录，不必重新输入口令。
5. 设置页改了城市但未保存，点返回后配置文件保持原样。
6. 语言按钮、登录、保存、阅读页分流、PNG 与机器 JSON 的现有行为保持。
