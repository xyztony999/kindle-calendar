## 2. Action 定义

| Action | 方法 | URL | 触发 | 对应 API |
|--------|------|-----|------|----------|
| `nav.home` | GET | `/` | 点返回首页，或点左侧站点名 | 已有首页 |
| `nav.lang` | GET | 当前页 `?lang=` | 点语言按钮 | 已有语言切换 |
| `nav.raw` | GET | 当前阅读地址 `format=json` | 点原始数据 | 已有机器原文 |
| `nav.image` | GET | 三个图地址，要网页 | 从首页点开图地址 | C-4 C-5 C-6 承载页 |
| `nav.png` | GET | 同一图地址 `format=png` | 点查看原图，或页面里的图片标签 | C-4 C-5 C-6 的 PNG |
| `theme.toggle` | 无请求 | Cookie `kc_theme` | 点明暗按钮 | 4.4.4，不新接口 |

不附带管理端写操作头。明暗不进保存请求。

确认项 4：没有 operList。

## 3. 字典

语言仍是 enum-pool.md §3 `ui_lang`。明暗是 §4 `ui_theme`。

按钮文字与 api-web-chrome.md 3.4 的文案表相同，不另造一套。

## 4. 顶栏

四类页面的操作按钮共用一种样子：高 34px，左右内边距 12px，圆角为全圆，1px 边框，背景用卡片色，文字用墨色，没有下划线，不用紫色。明暗是同高的 34px 图标按钮。

图标表示下一次会变成什么：当前是浅色时画月亮，提示「切换到深色」；当前是深色时画太阳，提示「切换到浅色」。跟随系统时，按系统算出来的那一种来画。

### 4.1 首页

现有顺序是语言、GitHub、管理端。只在语言按钮左侧插入明暗。GitHub 和管理端不动。

```
[ 站点名 ]          [ 明暗 ] [ English 或 中文 ] [ GitHub ] [ 管理端 ]
```

### 4.2 管理端

未启用、登录、设置都用这一条。站点名在左，点了去 `/`。右侧三枚按钮。设置页里的「退出登录」仍留在设置区，不进顶栏。

```
[ Kindle 台历 ]     [ 明暗 ] [ English 或 中文 ] [ 返回首页 ]
```

顶栏在内容区内，距页面上沿约 20px，不再贴死在视口最上沿。

### 4.3 阅读页

左侧站点名。右侧四枚，原始数据和返回首页都从贴角文字链挪到这里。页面距上沿留白约 22px。没有原文可给时不放原始数据。

```
[ Kindle 台历 ]     [ 明暗 ] [ English 或 中文 ] [ 原始数据 ] [ 返回首页 ]
```

### 4.4 图片承载页

```
[ Kindle 台历 ]     [ 明暗 ] [ English 或 中文 ] [ 返回首页 ]
```

图在顶栏下面，放在浅色画框里，深色页面也不把图反相。图下说明一行：「灰度图，与设备拉取的是同一张。」旁边按钮「查看原图」，新标签打开 `format=png`。

不放页签，不放上月下月。地址里已有的 `page`、`offset`、字形只决定这一张图。

确认项 2、3、5、6：无查询条件、无数据表格、无新表单分组、无单据详情 Card。

确认项 7：不做成独立的混合页或代码画布。登录卡和顶栏都在现有页面里。

## 5. 登录卡

页面背景跟随当前明暗（纸色或深色），不再是一块与主题无关的纯黑加上紫色链接。

卡片居中，最宽 400px，圆角 12px，内边距约 28px。

从上到下：

1. 44px 圆角方标，字是「历」。
2. 标题：中文「Kindle 台历 · 管理端」，英文「Kindle Calendar · Admin」。
3. 现有提示句。
4. 口令标签在输入框上方，输入框全宽。
5. 现有错误句的位置仍在按钮上方。
6. 「登录」主按钮全宽。

卡片里不再放「← 返回首页」。返回只在顶栏。

未启用版面用同一张卡片，只显示现有的未启用说明，没有口令框。

## 6. 深色下的管理端控件

截图里的问题是：数字框白底，右侧上下箭头灰，禁用的黄历一行几乎看不见。

深色时（已选深色，或没选且系统为深色）：

- 文本、口令、搜索、数字框：背景 `#2a2622`，字 `#f4f1ea`，边框 `#8a8175`。
- 数字框自带的上下箭头：箭头 `#f4f1ea`，箭头底 `#2a2622`。
- 复选框至少 16px。未选边框 `#8a8175`，勾选用 `#f4f1ea` 或 `#7eb6ff`。
- 行尾的上移、下移按钮：深底、浅色箭头、可见边框。
- 禁用行：背景仍是 `#2a2622`，字 `#c8bfb4`，不透明度不低于 0.75。

浅色不改现在的纸感和栅格。焦点环仍是 2px 墨色。

## 7. 明暗怎么切、怎么记住

没点过：跟随系统。系统换成另一种，页面跟着换。

点一下：若当时看起来是浅色，立刻变成深色；若当时是深色，立刻变成浅色。写入 `kc_theme`，一年，路径 `/`。再点就换回另一种，仍然记住。

不会在第三次点回「跟随系统」。浏览器里删掉这枚 Cookie 才会重新跟随。

首页、管理端三种版面、四张阅读页、三张图片承载页读同一枚 Cookie。从管理端点去首页，外观不变。

第一屏由服务端按 Cookie 写上标记，避免先闪一下相反的颜色。

## 8. 点击之后

1. 返回首页：地址变为 `/`，会话还在，未保存的设置不写入。
2. 语言：整页换成另一种语言，明暗选择保留。
3. 原始数据：当前页变成机器原文。env 仍是 env 文本。
4. 查看原图：新标签是 PNG，当前承载页还在。
5. 明暗：当前页立刻变，不刷新也可以；其它已打开的页在下次打开时一致。

## 9. 路由

| 路由 | 变化 |
|------|------|
| `/` | 顶栏多明暗按钮。机器清单不变 |
| `/admin` | 顶栏与登录卡 |
| 四个阅读地址 | 顶栏按钮位置 |
| 三个图地址 | 要网页时多一种 HTML；PNG 不变 |
| `/admin/api/*` | 无变化 |

## 10. 与现有页面的关系

| 页面 | 关系 |
|------|------|
| 网站首页 | 返回目标。本身只加明暗按钮 |
| 阅读页 | 内容块不动，只动顶栏 |
| 管理端预览图 | 仍用图片标签，必须拿到 PNG |
| 语言按钮 | 仍是单按钮，不改成两段 |
