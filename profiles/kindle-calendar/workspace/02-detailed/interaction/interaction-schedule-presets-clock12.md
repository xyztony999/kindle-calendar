# 交互：schedule-presets-clock12

- 版本：v1.0（2026-10-25）

## 1. 时钟 12/24（外观面板）

- 时钟积木选中 → 外观面板新增开关「12 小时制（1-12 + AM/PM）」，默认关。
- 开关后画布标签即时显示示例（如 "9:05 AM"），预览/真机在设备脚本更新后生效；未更新脚本的老设备维持 24h（服务端 env 兼容）。

## 2. 版面快照（「页面与轮播」卡片内）

```
┌ 页面与轮播                        [+ 新建页面] ┐
│ …页面列表…                                       │
│ ── 版面方案 ──                    [保存当前为方案] │
│ ● 简洁版 10-25 14:00  [应用][覆盖][删除][导出]    │
└──────────────────────────────────────────────┘
```
- 保存：输入名称（≤20 字）；覆盖：确认后用当前 pages/defs/assets 重写快照；应用：替换三块并标脏（先关弹窗），用户确认保存才落库；导出：下载 `<名称>.json`；删除：确认。
- 上限 8 套，满时禁用保存按钮并提示。

## 3. 日程卡（「我的积木」卡片之后）

```
┌ 日程 · ICS 订阅                                  ┐
│ [https://calendar.google.com/… ics] [−]          │
│ [+ 添加订阅链接]   ← 最多 3 个，仅 https          │
│ 说明：订阅链接保存在本服务器；每 6 小时自动刷新，   │
│ 失败时沿用上次结果。                              │
│ ── 纪念日 · 倒计时 ──             [+ 添加纪念日]  │
│ ● 妈妈生日  08-16  农历每年   [今天?/N 天] [−]    │
└──────────────────────────────────────────────┘
```
- 纪念日：名称 + 日期 + 重复（不重复/公历每年/农历每年）；行内即时显示距今天数。
- 「日程」「倒计时」新系统积木出现在编辑器调色板；月历「日程标记」开关默认关。
