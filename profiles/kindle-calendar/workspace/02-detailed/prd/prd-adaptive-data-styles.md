# 数据积木适用样式与画布实例外观

v1.0 / 2026-10-17 / Gate1用户已确认，实施与本地Gate2验证完成，待交付确认。

## D0 需求与决策

用户选中提议“更合理的做法是按所选数据提供适用样式”，要求按pipeline修改，并明确选择“移到画布，按页面单独设置”。前一轮admin-refinement及设备确认修复全部保留，本增量尚不代表其Gate2确认或提交授权。

创建数据积木负责名称与字段，画布实例负责样式。同一数据定义可以在不同页面，甚至同页不同实例，采用不同外观。选项由字段静态类别与数量决定，不随当天数值长度、缺失或天气变化跳动。

## 本轮样式

- hero / 突出首项：1–3项，首项为数字、时间或日期，其余均为紧凑字段；首值大字，其余标签和值。
- rows / 逐行列表：1–6项，适用全部字段；含长文本时自动换行并分配行高。
- horizontal / 横向指标：2–3项，全部为数字/时间/日期/短分类；指标等宽横排，值上标签下。
- grid / 网格卡片：2–6项，全部为紧凑字段；两列网格，奇数末格留空。

图表需要历史数据或量程，图标需要明确映射，本轮不新增这类样式。样式名称是同一组数据的排版选择，不新增数据来源。

## 流程与兼容

1. 创建只填写名称与1–6个字段，保持字段目录顺序；内部定义仍保留rows为兼容默认，不向用户要求创建时选样式。
2. 放入画布后自动选定推荐样式，右侧“当前积木外观”显示实际适用卡片及推荐标记：单项数字/时间/日期推荐hero；2–3项紧凑字段推荐horizontal；4–6项紧凑字段推荐grid；其余推荐rows。
3. 点击画布积木或使用键盘选择，才能改当前实例；选择其他积木后同步显示其设置。只影响当前block，不修改共享定义。
4. 选择样式后走既有防抖真实预览，完成只保留草稿，全局保存后下发；取消恢复本轮外观变化。删除选中积木后清除外观栏选择。
5. 旧配置1/2迁移后保留definition.style及布局坐标，无block.style时继续继承；历史hero长文本仍允许原样显示，标“原有样式”。显式选择新样式必须通过适用校验。
6. 导出升级schema3，接受旧1/2导入。旧服务不能静默忽略block.style后导入新文件，因此必须拒绝schema3。Kindle只收服务端PNG，无新增协议或脚本变更要求。

## 验收与异常

温度/湿度有横排与网格候选；一言正文/出处只显示列表。数字缺失显示—而不隐藏选项。旧hero外观可保留；同定义两页不同外观，取消恢复；预览/保存/导入导出/中心审核模板一致。中英长值、极小矩形采用缩字与换行，最小字号后仍超出则末行省略，保持内容在矩形内，原始字段值不截断。用户通过预览和调整尺寸判断效果。
