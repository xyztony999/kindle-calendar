### 0.1 已锁定、不再追问的决策

1. `天气台历.sh` 启动中文画面，`WeatherCalendar.sh` 启动英文画面。英文是真正的渲染语言，覆盖页眉、星期、天气描述、一周、月历、详情、黄历上的界面文字。
2. 语言由启动器传给 `dash.sh`，再进入云端请求。查询参数 `lang` 只取 `zh` 或 `en`。中文为默认。旧设备不带 `lang` 时行为不变。
3. 农历、节气、宜忌没有现成英文译名时降级：能译的界面词用英文，专名保留中文，或英文标签加中文原文。不新造术语。
4. 首页和管理端是同一套页面的中英文切换，不依赖 CDN。默认可跟浏览器 `Accept-Language`，切换后用 Cookie 记住。管理端校验提示随语言变化。
5. 不改鉴权、持久化、GPL-3.0、云端优先轮播。

## 1. 背景与目标

项目已按 GPL-3.0 开源，海外使用者会打开书库和网站。现在 Kindle 画面、首页和管理端都是中文。

**为谁**：在书库打开英文启动器的家庭用户，以及用浏览器看首页、登录管理端的维护者。

**价值**：英文启动器得到英文界面词；浏览器可以在中文和英文之间切换，并记住选择。

## 3. 角色

| 角色 | 本次操作 |
|------|----------|
| 家庭用户 | 点「天气台历」看中文画面；点「WeatherCalendar」看英文画面。后打开的一本会停掉前一本，这是现有启动器已经会做的事 |
| 维护者 | 把两本启动器一起复制到 Kindle `documents/`。在首页或管理端切换语言。英文下阅读校验提示，并看到英文预览图 |

带空格的「Weather Calendar」如果仍留在书库，打开后仍是中文。

## 4. 规则

### 4.1 设备语言

1. 书库书名是文件名去掉 `.sh`。英文入口的文件名就是用户点名的 `WeatherCalendar.sh`，书名显示为 WeatherCalendar。
2. `WeatherCalendar.sh` 在执行中文启动器之前声明本次为英文。中文启动器读取配置之后仍保留这个声明，配置文件不能把英文入口改回中文。
3. 中文启动器自己打开时不声明语言。`dash.sh` 只有在声明为英文时，才给云端地址加上 `lang=en`。
4. 进程环境变量不使用 `LANG`。避免改掉设备的区域设置。云端 env 文件若需要回传语言，使用小写 `lang`。
5. 没有 `dash.sh` 时的整图回退同样遵守：只有英文入口才请求 `lang=en`。
6. `Weather Calendar.sh` 继续只转入 `天气台历.sh`，并且不声明英文。
7. 已装在旧设备上、不会声明语言的脚本，请求保持今天的地址，画面保持今天的中文。

### 4.2 云端语言

设备与调试请求只看查询参数，不看 Cookie，也不看 `Accept-Language`。

| 顺序 | 条件 | 结果 |
|------|------|------|
| 1 | 没有 `lang`，或去掉空白后为空 | `zh`，响应与现在的中文响应一致，资产地址不追加 `lang` |
| 2 | `lang` 以 `zh` 开头 | 与缺省相同的中文响应 |
| 3 | `lang` 以 `en` 开头 | 英文界面词。env 里的分区地址带 `lang=en`，并有一行 `lang=en` |
| 4 | 其它值 | 与缺省相同的中文响应 |

分区图、整页图、`dashboard.json`、`dashboard.env`、`/weather` 使用同一规则。缓存和内容指纹按语言分开，中文设备不会拿到英文图，也不会因为英文图改变中文图的 ETAG。

`GET /` 在返回 HTML 之前，仍先判断 `format=json` 或 `Accept: application/json`。命中则返回现有接口清单，句子保持中文，`lang` 不改变这一点。

### 4.3 英文画面的范围与降级

英文要画进图里，不是只改脚本注释。界面词用英文。下面这些专名本仓库和 `lunar-python` 只有中文，本模块不新造译名。

| 内容 | 英文入口 |
|------|----------|
| 页名：今日、一周、月历、详情、黄历 | Today、Week、Month、Detail、Almanac |
| 页眉日期与星期 | 英文星期缩写 Mon–Sun，加阿拉伯数字月日，例如 `10 Oct`。不再用中文大写数字日期 |
| 月历表头与月份标题 | Mon–Sun；月份标题如 `October 2026` |
| 天气描述 | 与现有 WMO 代码同一张表的英文短语，见 API 文档。未知代码为 Unknown |
| 湿度、风、降水、今日温度范围等标签 | 英文标签，数字格式不变 |
| 休 / 班 | Off / Work |
| 空气质量等级 | 沿用现有六个数值断点的 US EPA 英文名：Good、Moderate、USG、Unhealthy、Very Unhealthy、Hazardous。不新造分级 |
| 暂无数据 | No data |
| 农历整句 | 英文标签 Lunar，后面保留中文原文（含闰月） |
| 干支 | 保留中文，不加自造英文 |
| 生肖 | 使用通用英文动物名：Rat、Ox、Tiger、Rabbit、Dragon、Snake、Horse、Goat、Monkey、Rooster、Dog、Pig |
| 节气 | 英文标签 Solar term、Day N、Next；节气名保留中文 |
| 物候 | 英文标签 Phenology，原文保留中文 |
| 宜 / 忌栏题 | Suitable / Avoid |
| 宜忌条目 | 保留 `lunar-python` 的中文原文 |
| 节日、假期名称 | 保留中文原文 |
| 一言正文、用户自定义文案 | 不翻译，只保留原文 |
| 时钟数字 | 不变，仍是 0–9 与冒号 |

页眉高度仍按现有约 78px 安排。英文用缩写，避免把现有分区撑破。字体继续用渲染模块已经选择的系统字体里的拉丁字形，不新增字体文件，不引用 CDN。

### 4.4 网页语言

首页 `server/templates/index.html` 与管理端 `server/templates/admin.html` 仍是 Flask 渲染的同一套页面。文案放在服务端的一张中英对照表里，缺了英文键不能临时现编。

判定顺序：

1. 查询参数 `lang` 去掉空白并小写后，以 `zh` 或 `en` 开头：采用该语言，并写入 Cookie。
2. 否则 Cookie `kc_lang` 为 `zh` 或 `en`：采用 Cookie。
3. 否则只在 `Accept-Language` 的 `en` 与 `zh` 两族里比质量。质量高的胜出；质量相同则先出现的胜出。
4. 两者都没有：中文。

Cookie：`kc_lang`，`Path=/`，`Max-Age=31536000`，`SameSite=Lax`，`HttpOnly`。请求是 HTTPS 时加 `Secure`，与现有会话 Cookie 的安全属性做法一致，但是另一枚 Cookie。切换语言不登录、不续期、不改会话。

页面上的语言开关链到当前路径的 `?lang=zh` 或 `?lang=en`。`html` 的 `lang` 为 `zh-CN` 或 `en`。

管理端页面内的脚本提示也来自这张文案表，包括未填口令、登录过期、搜索失败、字段校验。服务端错误响应的 `code` 保持现在的英文大写码；`message` 和 `details[].message` 使用当前网页语言。城市搜索上游的 `language` 参数在英文页面用 `en`，中文页面用 `zh`。保存进配置的城市名仍是用户选中的原文，不另存一份翻译。

英文页面的预览地址追加 `lang=en`。中文页面的预览地址保持现在的 `/dashboard.png?page=`。

### 4.5 明确不改

鉴权（口令、会话、限速、CSRF）、配置 JSON 的结构与文件、GPL-3.0、云端优先的轮播参数，都不因语言而改变。语言不是台历配置项，管理端不能把某台 Kindle 远程改成英文；设备语言只由那本被打开的启动器决定。

### 4.6 对象关系

| 对象 | 关系 |
|------|------|
| 英文启动器 | 依赖同目录中文启动器来拉起 `dash.sh`；自己只声明语言 |
| 中文启动器 | 依赖已安装的 `dash.sh`；没有时才用自身整图回退 |
| 画面语言 | 只存在于这一次请求。英文图与中文图分开缓存 |
| 网页语言 | 记在浏览器 Cookie，不写入设备，也不写入配置文件 |
| 历法专名 | 仍由现有历法计算产生。本模块只决定标签和是否原样保留 |
| 接口清单 | 与落地页互斥：同一次根路径响应要么是 JSON，要么是 HTML |

没有被其它流程写入的持久对象。不需要新的数据表字段。

## 6. 验收

1. 打开 `天气台历.sh`，五页界面词仍是现在的中文。不带 `lang` 的分区图与这次改动前的中文图一致。
2. 打开 `WeatherCalendar.sh`，页眉、星期、天气描述、一周、月历、详情、黄历界面词为英文；宜忌条目、节气名、农历、干支、节日名仍是中文。
3. 带空格的 `Weather Calendar.sh` 仍然进入中文画面。
4. `/?format=json`、`Accept: application/json` 仍是 JSON 清单，句子仍是中文。
5. 浏览器语言为英文且没有 Cookie 时，首页和管理端是英文。点中文后刷新仍是中文。管理端故意保存非法停留秒数时，提示为当前语言，错误码不变。
6. 登录口令、配置文件字段、轮播云端优先行为与改动前一致。
