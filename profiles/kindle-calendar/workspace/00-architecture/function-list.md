| 属性 | 值 |

| 版本 | v2.0 |

## 第一部分：文档概述

按用户类型列出可操作的菜单与功能点，作为功能开发、交互设计与验收的依据。v2.0 随业务/应用架构重划更新，并新增「浏览访客」用户类型（网站服务成为第二呈现通道）。

### 1.1 背景与目标

家庭用户「看什么、怎么翻」；浏览访客「逛网站、读数据」；维护者的操作面从「五页开关 + 城市」扩展为管理端六分区（页面/积木/日程/城市/一言/设备）与画布编辑器。本清单与 AA v2.0 模块一一对应。

### 1.2 文档定位

| 定位 | 说明 |
|------|------|
| 本文档做什么 | 按用户类型分章，列出每个用户可操作的菜单项和功能点描述 |
| 本文档不做什么 | 不涉及技术实现方案、不涉及数据库设计、不涉及接口定义和系统架构 |

### 1.3 范围

| 范围 | 说明 |
|------|------|
| 业务域 | Kindle 电子台历（BA v2.0） |
| 用户类型 | 家庭用户、浏览访客、维护者 |

## 第二部分：功能清单

### 本清单概览

家庭用户消费设备画面（观看与触摸操作，语言由书库启动器决定）；浏览访客消费网站（首页门户、接口阅读页、图片承载页与网页语言明暗，机器客户端访问同一地址仍得原文与 PNG）；维护者经管理端六分区与画布编辑器完成内容源选取、版面编排与配置治理。设备侧两类用户共享同一设备，无权限隔离需求；管理端为单管理员口令保护。

## 2.3 维护者

**用户类型概述**：台历的主人，经 Web 管理端六分区（页面/积木/日程/城市/一言/设备）与画布编辑器完成内容源选取、版面编排与配置治理。

#### 2.3.1 核心业务域

**应用域概述**：版面编排——管理端「页面」「积木」两分区与画布编辑器。

##### 2.3.1.1 版面编排

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 管理页面 | 预设五页启停与排序、自建页新建/重命名/删除（≤12 页） | C-08-01 | 今日页固定首位 |
| 配置轮播 | 轮播开关、每页停留秒数、触摸让位秒数、拉取间隔 | C-08-02 | 拉取间隔留空用设备值 |
| 编辑版面 | 画布编辑器：添加/拖动/缩放/层级/微调/移除积木，吸附可关，中途取消恢复草稿 | C-08-03 | 文字与上传图片元素同入口 |
| 配置积木外观 | 逐实例配置显隐/档位/图形/日期格式与模板/今日标记/指数项目与顺序/一周内容/边框 | C-08-04 | 未配置=出厂样式 |
| 管理数据积木 | 从 41 字段勾选组合定义、样式推荐、跨页放置 | C-08-05 | 卡片与编辑器抽屉双入口 |
| 管理图片素材 | 上传/删除图片（≤4MB），未引用回收 | C-08-06 | 需对象存储 |
| 管理版面预设 | 保存/应用/覆盖/导出/删除整包快照（≤8 套） | C-08-07 | 应用标脏不偷跑 |
