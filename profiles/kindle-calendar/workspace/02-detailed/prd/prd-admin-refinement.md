v1.0 / 2026-10-16 / 增量设计，Gate 1 已获用户confirm确认；实现和本地验证完成，Gate 2真机待验收。

## D0 需求与证据

继承 admin-feedback、web-admin、web-chrome。用户为维护者，设备为 Kindle。保留尚未完成的设备确认 HTTP 400 排查，并覆盖八条新浏览器反馈。

用户已更新 dash.sh，画面内刷新后配置实际生效，env 拉取正常，确认 POST 每次返回 400。当前服务仅 request.get_json(silent=True)，发送端 wget --post-data 为 JSON。BusyBox 1.17.1 源码会 URL_escape(post_data) 并追加 form Content-Type，本地模拟该请求可复现 400。真机 wget 具体版本尚未确认，因此这是有代码证据的兼容原因，不能宣称已真机验证。

start.sh 的 Gunicorn 每 200–240 次请求回收工作进程，HeartbeatLog 仅内存；状态记录会独立丢失。此前旧脚本导致未知的问题已通过更新 Kindle 脚本解决，本轮不放宽设备识别，也不把普通 wget/curl 访问视为设备。

## 范围与验收

1. 修复确认格式兼容，仍仅在资产与绘制成功后确认版本。JSON 客户端兼容；新脚本发标准表单；旧脚本 URL 编码 JSON 可解析；严格字段校验不变。错误原因可定位，网络失败不影响现有画面。
2. 心跳状态在 settings.json 同目录独立原子保存，工作进程回收后按原时间判断在线/离线，不重置为未知。损坏记录降级未知，写入失败保留进程内状态并记日志；不改变配置版本。
3. 新增页面移到“页面与轮播”卡片标题右侧，轮播开关和暂停秒数保留各自位置。
4. 保存、导入、导出、恢复默认移至设置标题下全宽吸顶操作条；保存突出，恢复默认保留危险操作样式。窄屏换行，不依赖滚到预览底部。
5. 样式文案改为“突出首个数据”“逐行数据列表”，加入真实名称和值的示例和最多3/6项说明。明确首项按字段列表顺序确定，不承诺点击顺序。
6. 编辑器增加取消。取消恢复打开前整个草稿（pages/widget_defs/assets），保留进入编辑前的未保存设置；新建页取消不残留空页。Escape/遮罩走取消；完成保留草稿，仍需全局保存。
7. 删除右侧重复 def-list；积木管理归属左侧“我的积木”，创建归属右侧表单。删除菜单说明涉及页面数并确认，仍清除所有引用；取消编辑可撤销本轮删除。
8. 共享已确认 Logo 到首页、管理端、阅读页、图片承载页与所有网页标签。SVG 适配主题，兼容 ICO 与触屏图标；Docker 镜像必须包含静态资源。
9. 城市保留现有400ms联想，移除冗余搜索按钮，单行输入；候选支持上下/Enter/Escape、中文输入法合成、请求乱序保护和无结果/失败提示。只选定候选后更新位置；经纬度/时区手动填写仍可用。
10. 一言库仅预留统一结构与接入设计，不实现任意URL抓取或新增可选来源。界面用简短说明告知未来可导入符合结构的语录库，不展示假按钮。
