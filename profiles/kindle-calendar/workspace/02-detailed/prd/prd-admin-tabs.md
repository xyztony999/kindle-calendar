# PRD：管理端页签制重构（admin-redesign-tabs）

- 版本：v1.0（2026-10-30 Gate 1 确认，用户按推荐执行：A 页签制 / 预览归"设备" / E2E 同步适配）
- 前置：前两轮（台历工房、收敛迭代）在单页长滚动结构上调样式，用户实测仍觉得乱——本轮动信息架构。

## R1 页签制工作台

- R1.1 顶栏（保存/导入/导出/备份/恢复/恢复默认）全局保留吸顶；其下页签栏替换原锚点导航。
- R1.2 五个页签 = 功能域，**每次只显示一个域**：
  | 页签 | data-tab | 内容 |
  |---|---|---|
  | 页面 | pages | 页面与轮播、版面方案、拉取间隔 |
  | 积木 | blocks | 我的积木、图片素材、每日一图提示 |
  | 日程 | schedule | ICS 订阅、纪念日·倒计时 |
  | 城市 | env | 城市搜索与坐标、一言 |
  | 设备 | device | 设备状态、数据源健康+点阵、页面预览 |
- R1.3 切换 = 容器/卡片显隐（data-tab 属性）；所有 DOM id、渲染函数、事件绑定不动；未保存状态跨页签保持（脏标记常显于吸顶工具条）。
- R1.4 删除 scroll-spy（被页签取代）；showView 切换后重绘页签状态。
- R1.5 设备页签独占时内容区收窄居中（右栏卡片原为窄栏设计）。

## R2 交互细节

- 页签切换即时（无动画）；页签高亮 = accent 底（沿用）。
- 空态引导、按钮分级、暗色提亮等收敛迭代成果全部保留。

## 非目标

- 页签记忆（刷新回默认"页面"）；页签级懒加载；预览常驻小组件。

## 验收

- 五页签切换正确显隐；各页签内功能回归全绿（E2E 适配后）；134 单测不动全过；移动端无横向溢出。
