# PRD：我的积木管理页、图片素材链路修复与版面编辑对齐（widget-manager）

- 版本：v1.0（2026-10-23 Gate 1 确认，用户按推荐方案拍板）
- 范围：管理端「我的积木」独立管理卡片、图片素材链路六项修复、版面编辑器智能吸附

## 1. 背景与问题

1. 「新增数据积木」与「我的积木」管理完全嵌在版面编辑弹窗内：列表只能改名/删除、字段不可改、图片素材无删除入口；用户希望有一个专门页面完成新增与管理。
2. 图片上传为数据积木链路异常：默认部署无 OSS 配置时上传直接 400；OSS 读取失败静默画白；空文件错误信息误导；透明 PNG 渲染发黑；取消编辑导致已上传素材被 GC 静默删除；无请求体大小上限。
3. 版面编辑器拖动积木只有 1px 取整，无任何对齐/吸附/键盘微调，积木容易放歪。

## 2. 需求与验收

### R1 我的积木管理卡片（主视图，置于「页面与轮播」之后）

- R1.1 数据积木列表行：名称 | 字段摘要（全部字段标签）| 用于 N 页 | 编辑 | 删除。
- R1.2 新建/编辑共用表单：名称（≤20 字）+ 字段复选（1–6 项）+ 首字段提示 + 保存/取消；上限 `max_defs=12`。
- R1.3 字段变更后自动重算：def.style 与所有引用该 def 的积木实例 style 若不再适用则回退推荐样式（服务端校验兜底）。
- R1.4 删除数据积木：确认文案沿用现有（含引用页数，取消编辑可撤销）。
- R1.5 图片素材区：每素材一行（id | 图片素材 | 删除）；删除需确认，从引用页面移除 image 积木；保存后由 GC 从 OSS 一并清除。
- R1.6 版面编辑弹窗左栏简化为放置列表：保留点击/拖放放置、+ 文字、+ 上传图片；行内重命名/删除移除；提供「管理我的积木」入口（完成编辑并滚动到管理卡片）；弹窗右栏 def-editor 移除（新建入口迁移到管理卡片）。

### R2 图片素材链路修复

- R2.1 `widget-catalog` 返回 `storage.configured`；前端未配置时禁用上传按钮并提示原因（复用 `oss_missing` 文案）。
- R2.2 渲染占位：素材取不到时该区域画语言无关的"缺图"图标（灰框+对角线），不再静默纯白；`storage.get_object` 未配置时写 warning 日志。
- R2.3 空 multipart（无 file 字段/无文件名）返回 `ASSET_EMPTY`「未收到图片文件」；`inspect_image` 对空字节同样报 `ASSET_EMPTY`。
- R2.4 透明 PNG（RGBA/LA/PA/带透明信息 P 模式）先合成白底再灰度，避免发黑。
- R2.5 取消编辑时若本次会话上传过素材，弹确认「取消将一并删除」；确认后照常回滚。
- R2.6 `MAX_CONTENT_LENGTH=4MB` + 413 JSON 错误响应。
- R2.7 部署配置：docker-compose 系列透传 `OSS_*`（与 `WIDGET_CENTER_URL`）环境变量；DEPLOY.md 增加 OSS 开通配置章节与 FAQ。

### R3 版面编辑器对齐吸附

- R3.1 拖动吸附（阈值 8 设计 px）：候选线=画布参考线（x: 0/56/379/702/758，y: 44/512/1024）+ 其他积木的左/中/右、上/中/下边缘；命中时块吸附并显示参考线。
- R3.2 缩放手柄吸附右/下边缘到同一组候选线。
- R3.3 调色板拖入/点击落点（`place(at)`）过吸附（无参考线显示）。
- R3.4 工具栏「对齐吸附」开关，默认开，localStorage 记忆；按住 Alt 临时禁用。
- R3.5 选中积木后方向键 1px 微调，Shift+方向 10px；输入控件聚焦时不劫持；移动后保持焦点。
- R3.6 吸附后仍钳制边界（x≥0、y≥44、不出画布）；服务端零改动。

## 3. 非目标

- 不做独立路由页/多页管理端架构改造。
- 不做网格档位制（保持自由画布）。
- 不新增积木 REST 资源（CRUD 仍走 `settings/save` 全量提交）。
- 不做素材回收站/软删除。
