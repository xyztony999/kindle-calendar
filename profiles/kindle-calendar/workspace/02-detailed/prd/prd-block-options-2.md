# PRD：block-options-2（积木自定义二期）

- 版本：v1.0（Gate 1 草案，2026-11-08）
- 启动模式：冷启动（/pipeline，会话编排轨；master @ 022830e）
- 契约文档：`02-detailed/api/api-block-options-2.md`

## 1. 背景

用户反馈编辑器「当前积木外观」面板的勾选框挤成一团，并提出一批积木自定义需求。勘察结论：

| 问题 | 根因 |
|---|---|
| 勾选框挤在一起 | **回归**：`.opt-list/.opt-row/.opt-pick` 样式 8277d50 加入、a1937d4（台历工房 `<style>` 全量重写）丢失；JS 仍输出类名、无样式→行内流排 |
| 体感 -0° | **全站性**：10 处温度均 `f"{x:.0f}°"`，-0.4 格式化为 "-0" |
| 逐时/指数不可定制 | `render_hourly` / `render_indices` 无 options 参数，柱形图与六卡写死 |
| 逐时首个时间标签残缺 | 刻度文字以柱心居中，首柱 x≈10px，「22时」左半被裁成「2时」 |

## 3. 功能说明

### 3.1 勾选框排版（#0）
- 外观选项：每个布尔项独占一行（复选框＋名称，左对齐），单选项一行「名称：○大 ○中 ○小」。
- 数据积木字段（新建/编辑积木表单、编辑器抽屉）：按 天气 / 日期 / 农历 / 日出月相 / 空气 / 一言 / 日程 / 生活建议 分组，组名小标题＋组内自适应多列网格。

### 3.2 全局显示单位（#2 #7 #8）
「城市」分区新增「显示单位」组：温度 ℃/℉、风速 km/h·m/s·风力等级、AQI 标准 美标/国标。影响所有出图（今日天气、一周、逐时、指数、数据积木、降温提醒、日出月相卡 AQI）。数据接口（/weather、dashboard.json）仍按 ℃/km/h/美标原值输出，不受影响。

### 3.3 页眉日期格式（#1）
页眉外观选项新增「日期格式」：
| 键 | 中文页 | 英文页 |
|---|---|---|
| cn（默认，现状） | 十一月八 | 8 Nov |
| md | 11月8日 | Nov 8 |
| ymd | 2026年11月8日 | 8 November 2026 |
| dot | 11.08 | 11.08 |
| custom | 按模板 | 按模板（中文数字占位回退阿拉伯数字） |

选「自定义」时出现模板输入框：占位符 `{Y}{M}{MM}{D}{DD}{CM}{CD}{W}`，≤24 字（按模板写法计）；未知占位符或未闭合花括号就地报错；模板为空回退 cn；过长的日期先缩字、再截断加「…」，不压页签。

### 3.4 月历今日标记（#10）
月历网格外观选项「今日标记」：圆圈（现状）/ 实心反白（墨色实心圆＋白字）/ 方框。三者均以数字墨水包围盒定位（沿用 022830e 修复）。

### 3.5 逐时图表（#4）
| 选项 | 取值（首项为默认=现状） |
|---|---|
| 图形 | 柱形 / 折线 / 面积（网点灰填充） |
| 时间跨度 | 24 小时 / 12 小时 |
| 降水显示 | 圆点标注（≥30% 打点，≥50% 标数字）/ 底部细条 / 关闭 |
| 温度标注 | 首尾 / 最高最低 / 每 3 小时 |
| 刻度间隔 | 每 6 小时 / 每 3 小时 |

刻度与温度标注文字一律钳制在分区内（修首标签裁切）。

### 3.6 指数卡（#5 #5' #6）
外观选项「显示项目」：全部候选列表，勾选决定显示，已选项带 ↑↓ 调序；最多 6 张、至少 1 张；卡片数 ≤4 时自动放大（2 列×2 行，≤2 张单行）。候选 21 项：

| 分类 | 项目 |
|---|---|
| 现有（默认六卡） | 湿度、风速、降水概率、日出、日落、AQI |
| 现有数据补足 | 体感温度、今日高低温、月相 |
| 气象扩展 | 紫外线、气压、能见度、风向 |
| 空气细分 | PM2.5、PM10 |
| 生活建议 | 穿衣、晾晒、运动、洗车、感冒、防晒 |

以上新数据同时成为自定义数据积木的可选字段（#6）。生活建议为规则推算的主观建议，判定规则见契约文档 §7。

### 3.7 一周积木（#9）
一周列表：天数 7/5、降水概率开关（默认关）、天气图标开关（默认开）。一周曲线：天数 7/5。

## 5. 验收标准

- 未配置任何新选项时，各页面出图与 022830e 像素一致（-0° 修复与 .5 进位口径变化除外，单测固定）。
- 每个新选项：单测覆盖校验（非法值拒绝）、normalize 保留、渲染像素差异（on/off 墨量对比或几何断言）。
- 管理端：外观选项行式（几何断言：各行 y 递增、复选框在行盒内）；字段分组标题存在；E2E 两套 PASS。
- 全端点 HTTP 回归（含 /r/ 各分区多 offset、layout-preview）全 200。
