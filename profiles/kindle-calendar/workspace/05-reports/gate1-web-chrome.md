## 进入代码前需要确认

1. 确认本判定，确认后才改页面。
2. 确认明暗是两态：没点过跟随系统；点按钮只在深色和浅色之间换，并记住一年。不提供第三下回到跟随系统。若要改成「自动 / 浅色 / 深色」循环，需要先改设计。
3. 确认语言仍是一个按钮（中文页 English，英文页 中文），不改成「中 / EN」分段。
4. 确认顶栏位置：管理端右侧为明暗、语言、返回首页；阅读页右侧为明暗、语言、原始数据、返回首页；首页只在语言按钮左侧加明暗。登录卡里不再放第二条返回链接。
5. 确认图片承载页只覆盖 `/r/<page>/<region>.png`、`/r/today/clock/<glyph>.png`、`/dashboard.png`。浏览器要网页才出 HTML；wget、curl、`*/*`、图片标签和 `format=png` 仍是原来的 PNG。
6. 确认深色控件按文档色值：数字框深底浅字，箭头不是白底灰箭头，禁用的黄历行仍能读。
