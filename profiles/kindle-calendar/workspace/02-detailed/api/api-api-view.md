| 属性 | 值 |
|------|-----|
| 模块 | api-view |
| 版本 | v1.0 |
| 状态 | 稳定 |
| 最后更新 | 2026-10-11 |
| 输入 | prd-api-view.md v1.0 |
| 技术规约 | 无激活技术栈。沿用现有 GET。不引入企业 POST 三段路径、Result 包装或数据表 |

## 1. 模块设计概述

### 1.1 业务背景及目标

首页上的台历数据、天气、服务状态和设备清单，浏览器点开后是整页 JSON 或 env 文本。本模块让这四个地址在浏览器里变成阅读页。Kindle、部署脚本和首页状态脚本继续拿到原来的正文。价值是人能读，机器契约不变。

### 1.2 边界说明

| 边界 | 说明 |
|------|------|
| 做 | 四个现有 GET 的呈现分流、阅读页版头语言、原始数据链接、`Vary: Accept` |
| 不做 | 新表、新字段、新鉴权、改 PNG、改管理端接口、改首页机器清单、给 JSON 上色、改 env 行内容 |

### 1.3 设计决策

| # | 决策点 | 选择 | 理由 |
|---|--------|------|------|
| AD-0 | 管理模式 | 不适用 | 工具类，无自管/托管数据，无写入表 |
| AD-1 | 分流信号 | `format` 优先，其次 Accept 里写明的 `text/html` 与 `application/json` 质量 | 不看 User-Agent，避免把 `fetch` 和 `curl` 误判成浏览器页面 |
| AD-2 | 缺省 | 机器原文 | `*/*`、没有 Accept、质量相等都走原文，设备不会拿到 HTML |
| AD-3 | `format=json` | 四个地址都表示要机器原文 | 与首页已有参数同名。env 的原文仍是 `text/plain` |
| AD-4 | 未知 `format` | 机器原文 | 不把拼错的参数渲染成网页 |
| AD-5 | 阅读页语言 | 网页语言规则，版头与数据一致 | 从英文首页点进来应看到英文描述 |
| AD-6 | 机器语言 | 仍只看查询参数 `lang` | 与双语设计的设备规则一致，Cookie 不能改变 Kindle 的正文 |
| AD-7 | 原始数据链接 | 中文 `format=json`；英文再加 `lang=en`；健康检查只加 `format=json` | 原文和眼前页面的语言一致 |
| AD-8 | 缓存 | 成功响应加 `Vary: Accept` | 防止中间缓存把阅读页发给设备 |
| AD-9 | 心跳 | env 在正文成功生成之后记录，阅读页与原文相同 | 不改变「拉到清单才算一次拉取」 |
| AD-10 | 失败 | 机器分支不捕获；阅读页在组装失败时返回 500 的「暂时读不到」 | 不发明新的 JSON 错误体 |
| AD-11 | 呈现 | 分块阅读，不渲染 JSON 树 | 用户要的是可读页面 |
| AD-12 | 首页链接 | 不改 href，不改首页文案 | 浏览器点原链接即可；避免改动未提交的首页文案 |

### 1.4 领域对象总览

| 对象 | 角色 | 说明 |
|------|------|------|
| 台历载荷 | 关联领域对象 | 已由数据聚合组装。本模块只读，不增删键 |
| 天气切片 | 关联领域对象 | `/weather` 今天返回的 `current`、`daily`、`hourly` |
| 服务状态 | 关联领域对象 | `/health` 今天返回的字段，外加现有的 `status` |
| 设备清单文本 | 关联领域对象 | 已生成的 env 全文 |
| 呈现选择 | 过程数据 | 一次请求上的阅读页或机器原文，不入库 |
| 网页语言 | 过程数据 | 复用 enum-pool.md §3 `ui_lang`，不新增取值 |

无聚合根，故无混合模式声明表。无子流程。

### 1.5 上下文映射

| 对方 | 关系 | 说明 |
|------|------|------|
| 数据聚合 | 上游只读 | 阅读页展示已经组装的载荷 |
| 双语网页 | 上游规则 | 版头语言、单按钮和系统深色沿用已有网页规则 |
| 设备与脚本 | 遵奉者 | 不声明网页的请求维持今天的正文 |
| 管理端心跳 | 上游记录 | 只有成功生成 env 才记一次，阅读页不另造心跳 |

说明列只描述业务关系。

## 2. 跨聚合根设计

不适用。本模块没有聚合根。台历载荷仍只在既有数据文档里定义。

## 3. 应用/基础设施层设计

### 3.1 接口规范

不新增路径，不把 GET 改成 POST，不用 `Result<T>`。

| 端点 | 机器原文 | 阅读页 |
|------|----------|--------|
| `GET /api/v1/dashboard.json` | 现有 JSON | 台历阅读页 |
| `GET /weather` | 现有 JSON | 天气阅读页 |
| `GET /health` | 现有 JSON | 服务状态阅读页 |
| `GET /api/v1/dashboard.env` | 现有 `text/plain` env | 设备清单阅读页 |

下列端点本模块不修改：

| 端点 | 保持 |
|------|------|
| `GET /` | 先判 JSON 清单，否则首页。清单句子仍是中文 |
| `GET /admin` 与 `GET/POST /admin/api/*` | 现有页面与 JSON |
| `GET /dashboard.png`、`GET /r/<page>/<region>.png`、`GET /r/<page>/clock/<glyph>.png` | 现有 PNG、ETag、304 |

权限：四个地址仍是公开只读。阅读页不要求登录。

用户类型：维护者使用阅读页；机器客户端使用机器原文。

### 3.2 依赖与约束

| 依赖方 | 依赖什么 |
|--------|----------|
| 阅读页 | 现有载荷、天气切片、健康信息和 env 文本 |
| 英文阅读页 | 现有 `lang=en` 的载荷语言，不在本模块新造译名 |

| 被依赖方 | 说明 |
|----------|------|
| `dash.sh` | 依赖 env 正文仍可被 source，且不以 HTML 标记开头 |
| 首页状态脚本 | 依赖 `GET /health` 在 `Accept: */*` 时仍是 JSON |
| 部署检查 | 依赖 `curl /health` 仍是 JSON |
| 现有测试 | 依赖不带网页声明的 JSON 字段不变 |

约束：不得用 User-Agent 分流。不得在机器原文里插入说明文字。env 阅读页展开区里的文本必须与同语言机器原文一致，但机器响应本身不能包在 HTML 里。

### 3.3 权限模型

不新增角色。

| 操作 | 家庭用户 | 维护者 | 未登录浏览器 | 机器客户端 |
|------|----------|--------|----------------|------------|
| 打开阅读页 | 不提供设备菜单；若自行用浏览器打开公开地址，看到的与维护者相同 | 可以 | 可以 | 不会，除非它声明要网页 |
| 取机器原文 | — | 可以，用原始数据链接 | 可以 | 可以 |
| 保存配置 | 不可以 | 仍走现有管理端 | 不可以 | 不可以 |

数据权限：无多租户。语言 Cookie 不是登录凭证。

### 3.4 公共规范

| 枚举 | 来源 | 取值 |
|------|------|------|
| `ui_lang` | enum-pool.md §3 | zh / en。本模块不新增取值，不改池文件 |

`format` 不是领域枚举，只是一次请求的开关：`json`、`html`，或空。不写入枚举池。

错误码：不新增。组装失败不包装成新的业务码。配置项：不新增。

## 4. 详细设计

无聚合根。本节按工具的输入输出写契约，不建表。

### 4.1 领域模型

不适用数据表。标准审计字段、乐观锁、软删除、业务编码、主键均不适用。

不变量：

- INV-1 不带 `format`、且未写明 `text/html` 质量高于 `application/json` 的请求，四个地址的成功正文与本模块加入前一致（同一数据与同一 `lang` 下）。
- INV-2 `format=json` 时，即使 Accept 写明要网页，三个 JSON 地址仍是原来的 JSON，env 仍是原来的文本。
- INV-3 机器原文不读取 Cookie 和 `Accept-Language`。
- INV-4 阅读页不增加、不删除、不重命名 JSON 键，也不改 env 的键和行。
- INV-5 PNG 的字节、ETag 和 304 行为不变。
- INV-6 成功分流响应包含 `Vary: Accept`。

### 4.2 状态模型

不适用。呈现选择没有草稿、审批或生效状态。

### 4.3 子流程

无。

### 4.4 接口设计

#### 4.4.1 分流算法

对四个地址，按下面顺序得到呈现，命中即停止：

| 顺序 | 条件 | 呈现 |
|------|------|------|
| 1 | `format` 去空白后等于 `json`，忽略大小写 | 机器原文 |
| 2 | `format` 去空白后等于 `html`，忽略大小写 | 阅读页 |
| 3 | `format` 去空白后非空，且不是上两行 | 机器原文 |
| 4 | Accept 中 `text/html` 的质量 > `application/json` 的质量，且 `text/html` 质量 > 0 | 阅读页 |
| 5 | 其它，包括没有 Accept、只有 `*/*`、质量相等 | 机器原文 |

质量只认写明的 `text/html` 和 `application/json`。`*/*` 的质量不代入这两边。未出现的类型质量为 0。

浏览器常见的 `text/html` 质量为 1、未写 `application/json`，命中第 4 行。`fetch` 与 `curl` 的 `*/*` 命中第 5 行。

#### 4.4.2 语言

| 呈现 | 语言来源 | Cookie |
|------|----------|--------|
| 机器原文 | 仅查询参数 `lang`，规则与现有设备语言相同 | 不写 |
| 阅读页 | 与首页相同：查询参数 `lang`，其次 `kc_lang`，再是浏览器语言，最后中文 | 仅当查询参数明确给出 `zh` 或 `en` 时写入，写法和首页相同 |

阅读页用这个网页语言去取载荷或 env。因此英文网页看到的描述与 `lang=en` 的机器原文一致，但机器请求本身仍不会因为 Cookie 变成英文。

#### 4.4.3 台历阅读页

`GET /api/v1/dashboard.json` 的阅读页展示现有载荷中的这些块：地点、`generated_at`、`pages`、`settings_version`、`date`、`holiday`、宜忌、节气、`weather.current`、`sun` 的日出日落与已有月相名称、`aqi`、`quote`。

`holiday` 为空则不显示班休行。`aqi` 为空则写暂无。`quote` 展示已有的正文和出处字段。逐时数组不在本页展开，提供指向 `/weather` 的链接。该链接不带 `format`，以便浏览器继续看到阅读页。

机器原文仍是 `get` 这个地址今天返回的整份 JSON。

#### 4.4.4 天气阅读页

`GET /weather` 的阅读页只展示这份 JSON 已有的三块：

| 块 | 内容 |
|----|------|
| 当前 | 温度、描述、湿度、风速 |
| 逐日 | 日期、描述、最高、最低 |
| 逐时 | 时间、温度、降水概率 |

不把 `precip_prob` 添进 `/weather` 的 JSON。标题上的城市名来自现有载荷的地点，不新增字段。

#### 4.4.5 服务状态阅读页

`GET /health` 的阅读页展示现有字段：`status`、`screen`、`location`、`settings_version`、`pages`、`has_weather`、`weather_age_seconds`、`refreshing`、`last_error`。

`has_weather` 为假时，页面写明天气暂不可用，HTTP 仍是 200。`last_error` 按原文显示。

机器原文的字段集合与本模块加入前相同。

#### 4.4.6 设备清单阅读页

`GET /api/v1/dashboard.env` 的阅读页：

| 摘要项 | 来源 |
|--------|------|
| 屏幕宽高 | env 中的 `SCREEN_W`、`SCREEN_H` |
| 页面顺序 | `PAGES` |
| 轮播 | `ROTATE_ENABLED`，以及各页 `ROTATE_<页>_S`、`ROTATE_SUPPRESS_S` |
| 配置版本 | `SETTINGS_VERSION` |
| 语言行 | 有 `lang=` 则显示；没有则说明未声明、设备按中文 |
| 分区地址 | 统计 `_URL=` 行数，不在摘要里展开每条坐标 |

可展开区域中的文本与同语言机器原文逐字相同，包含末尾换行。页面其它位置说明：成功打开本页会计一次拉取。

机器原文的生成顺序不变：先生成文本，成功后再记心跳，然后返回。阅读页使用同一次生成结果，不生成两次以免心跳记两次。

#### 4.4.7 原始数据链接与语言按钮

| 当前阅读页 | 原始数据链接 |
|------------|----------------|
| 中文的台历、天气、设备清单 | 同一路径 `?format=json` |
| 英文的台历、天气、设备清单 | 同一路径 `?format=json&lang=en` |
| 服务状态 | 同一路径 `?format=json` |

语言按钮链到同一路径的另一种 `lang`，不附带 `format`。返回首页链到 `/`。

#### 4.4.8 失败与转义

载荷或 env 无法生成时，机器分支保持今天的未捕获失败。阅读页返回状态 500 的简短页面，标题说明暂时读不到，不显示堆栈。

所有来自数据的字符串（城市、描述、一言、`last_error`、env 原文）都按页面文本写入。

### 4.5 领域事件与集成

无领域事件，无消息队列，无新的仓储。关联调用只有读取现有载荷、健康信息和 env。
