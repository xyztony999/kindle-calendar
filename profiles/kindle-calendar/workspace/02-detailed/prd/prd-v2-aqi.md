## 1. 背景与目标

用户要求把今日页的月相盘替换为空气质量（AQI）显示。月相在台历场景信息价值低（当前残月 2% 只是一弯细牙），而秋冬空气质量是高频关注信息。

**目标**：
- G1：今日页原月相盘位置显示 AQI（US AQI 数值 + 等级文案 + 等级刻度条）；
- G2：详情页生活指数卡中「月相」卡替换为「AQI」卡（数值 + 等级）；
- G3：月相信息彻底移除（含服务端 astro 月相计算在 payload 中的暴露、场景图月亮保留为风景元素）。

**不做**：中国 AQI 标准计算（US AQI 零计算已确认）、历史趋势、多站点对比、月相在其它页面的留存。

## 2. 角色与场景

| 角色 | 场景 |
|------|------|
| 家庭用户 | 出门前看一眼今日页 AQI 判断是否戴口罩/开净化器；详情页看 AQI 数值与等级 |

## 3. 功能需求

### FR-1 空气质量数据拉取（S-01-05 新增）

- 数据源：Open-Meteo Air Quality API（`https://air-quality-api.open-meteo.com/v1/air-quality`），`current=us_aqi`；
- 安全基线：https + 域名白名单（air-quality-api.open-meteo.com）+ 禁重定向（与既有 weather/holiday/quotes 同模板）；
- 缓存：跟随天气拉取周期（同一 stale-while-revalidate 调度），不单独定频；
- 失败降级：`aqi = null`（payload 显式为 null，前端渲染占位），不重试雪崩（沿用天气退避）。

### FR-2 今日页 AQI 卡（C-01-04 扩展）

- 位置：sun 分区右半（原月相盘位置），弧线下方区域；
- 内容：`AQI` 大字数值 + 等级文案（Good/Moderate/USG/Unhealthy/Very Unhealthy/Hazardous → 中文：优/良/轻度敏感/中度/重度/严重）+ 六段等级刻度条（当前等级段高亮）；
- 失败：数值显示 `--`，等级显示 `暂无`，刻度条不画。

### FR-3 详情页 AQI 卡（C-05-02 扩展）

- indices 六卡布局不变：湿度/风速/降水概率/日出/日落/**AQI**（原月相卡位）；
- 内容：`{us_aqi}` 大字数值 + 等级文案；失败显示 `暂无数据`。

### FR-4 月相移除

- payload 保留 `sun.phase/illumination/name`（场景图 `scene._moon` 仍需 phase 画月亮，**不删除数据**）；
- 今日页 sun 分区与详情页 indices 卡不再渲染月相（渲染层移除）。

## 4. 业务规则

| 编号 | 规则 |
|------|------|
| BR-1 | AQI 等级按 US EPA 六级划分：0-50 优 / 51-100 良 / 101-150 轻度敏感 / 151-200 中度 / 201-300 重度 / 301+ 严重 |
| BR-2 | 拉取失败或数值缺失时显示 `--` 占位，不猜测不缓存过期值超过 24h |
| BR-3 | 数据源白名单制：仅 air-quality-api.open-meteo.com，https，禁重定向 |
| BR-4 | 灰阶呈现：数值 INK、等级 MID、刻度条四档灰阶（不引入新灰度） |

## 5. 非功能需求

| 编号 | 需求 |
|------|------|
| NFR-1 | AQI 拉取不增加设备端任何工作量（纯服务端渲染进现有分区） |
| NFR-2 | AQI API 超时 ≤ 10s，失败不阻塞天气/其它数据（独立 try/except） |
| NFR-3 | env 契约零变化（分区结构、URL、坐标均不变，仅 ETAG 随内容更新） |

## 6. 验收标准

1. 今日页原月相位置显示 AQI 数值/等级/刻度条；残月细牙不再出现；
2. 详情页第六卡显示 AQI（原月相卡消失）；
3. 断开 AQI 数据源（模拟超时）时今日页显示 `AQI --`、详情页显示 `暂无数据`，其余页面不受影响；
4. 月相不出现在今日页与详情页（场景图风景月亮保留）；
5. 全端点回归 200，env 契约无破坏性变化。

## 7. 开放问题

无（三项决策已锁定：彻底移除月相 / US AQI / `--` 占位）。
