# 自定义语录库格式（预留）

> **状态更新（2026-10-27）**：一言已内置官方开放句子库（`server/quotes_library.json`，AGPL-3.0，来源 hitokoto.cn），管理端可选 12 个分类（模块 quote-library）。本文件描述的"个人语录库上传"格式仍为预留规范。

本格式用于未来接入个人语录库，目前只提供规范与示例。管理端现有“自定义文案”仍通过逐条输入使用；设置导入接收的是完整台历设置，不能直接导入本文件。当前没有语录库上传或自定义接口地址功能。

## JSON 格式

文件使用 UTF-8 编码。顶层 `schema_version` 固定为整数 `1`，`quotes` 为非空数组，每项含 `text` 和 `from` 字符串。示例见 [quote-library.example.json](quote-library.example.json)。

```json
{
  "schema_version": 1,
  "quotes": [
    {"text": "此心安处是吾乡。", "from": "苏轼《定风波》"},
    {"text": "今天也留一点时间读书。", "from": ""}
  ]
}
```

字段约束沿用当前自定义文案：

- `quotes` 包含 1–100 条。
- `text` 去除首尾空白后为 1–32 个 Unicode 字符。
- `from` 为出处、作者或二者合并，去除首尾空白后最多 16 个 Unicode 字符；没有出处使用空字符串。
- 两个字符串都不能包含回车或换行，不接受 HTML。字符数不按 UTF-8 字节数计。
- 导入前应完整校验整份文件，指出错误条目的索引，避免静默截断或只导入部分内容。

语录库的 `schema_version` 与完整台历设置的版本号独立，不能混用。

## 未来接入边界

本地 JSON 库和在线服务都应经过来源适配器转换，向现有显示层提供同一个结果：`{"text": "…", "from": "…"}`。第三方的 `content`、`author`、`source` 等字段由适配器映射，不进入显示层；`from` 的合并规则须明确，不能自动丢失作者或出处。

在线接入仍需单独设计地址限制、认证信息保管、超时、缓存和重定向处理，不能把语录库格式视为允许任意地址请求。成功返回的内容必须通过上述校验；拉取失败或内容无效时回退现有离线诗词，避免台历空白。轮换、去重、语言选择及更新频率由来源实现决定，不作为这版文件格式的隐含约定。

当前 `server/quotes.py` 的 `get_quote()` 已输出 `text` / `from`，`server/settings.py` 对自定义文案施加相同的 32 / 16 字与 100 条限制；未来实现应复用这些约束。
