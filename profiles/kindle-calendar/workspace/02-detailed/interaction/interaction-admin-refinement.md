# 管理端体验交互增量

v1.0 / 2026-10-16，继承 interaction-admin-feedback。

## 设置主页面

顶栏保持站点/主题/语言/首页/退出。标题与配置版本下方放全宽吸顶操作条：保存主按钮，导入与导出次按钮，恢复默认危险按钮；清晰显示未保存状态。操作条在编辑弹窗之下，不盖住弹窗，手机自然换行。

页面与轮播卡标题右侧为“+ 新增页面”。标题下轮播开关，随后页面列表，最后暂停轮播秒数。城市搜索为单行输入框、下拉候选与状态行，取消独立搜索按钮。候选支持键盘与鼠标选择，旧请求不能覆盖新查询；输入法合成结束后触发联想。无结果时提供手动填写入口，现有城市/坐标/时区字段继续可编辑。

## 编辑弹窗

标题右侧并列“取消”“完成”。取消/Escape/遮罩恢复进入前完整草稿；完成接纳本轮编辑到未保存草稿。说明“完成后仍需保存配置”。打开新页前快照，取消移除临时页。上传完成但取消时仅撤销草稿引用，沿用现有孤立资产清理策略；异步上传/预览结果不得回写已取消会话。

右侧仅名称、样式、字段与创建按钮。两种样式：突出首个数据（最多3项，字段列表首项大字显示，其余为名称与值）；逐行数据列表（最多6项，每行显示名称与值）。样例明确显示当前温度24°、湿度60%、风速3.2，不再用无含义横线代替所有标签。展示首个已选字段名称，避免误解勾选先后。

左侧“我的积木”每项提供添加与更多操作菜单，删除位于菜单中；提醒将从N个页面移除。画布×仍只移除当前页实例。右侧不重复已有定义列表。

## 品牌与语录库

首页、管理端、阅读页和图片承载页的站点标志统一；浏览器标签使用相同图形，保留原站点名称与明暗配色。页面正文/墨水屏内容不额外盖Logo。

一言设置保留三种现有来源，加简短“语录库接入规划中”说明和统一格式文档链接；不放尚不能工作的选择项。
