# PRD：一言在线获取韧性（quote-resilience）

- 版本：v1.0（2026-10-26 Gate 1 确认，用户按推荐执行 A+英文同步）
- 根因（服务器实测）：hitokoto 走 Cloudflare 免费版无中国节点，阿里云北京 ECS 绕行洛杉矶 POP（colo=LAX），晚高峰跨洋丢包 ~80%，随机击穿 TLS 握手/TTFB 撞穿 8s 读超时；一条 A 记录对本机 SYN 黑洞；international 子域解析同一对 IP 换域无效。请求参数经官方文档核对合规，非姿势问题。

## 需求

- R1 超时拆分放宽：连接 5s / 读取 12s（元组超时）。
- R2 失败重试：超时/连接/HTTP 错误重试 1 次（间隔 1s；日频请求不触碰官方 2 QPS 限制）。
- R3 上次成功粘性缓存：在线失败时沿用最近一次在线成功内容（≤7 天），超龄回退内置离线库；健康卡照实显示失败与错误。
- R4 英文 zenquotes 同样处理（超时/重试/粘性缓存独立一份）。
- R5 不改：端点/参数（合规）、ALLOWED_HOSTS、离线库、健康 API 结构。

## 非目标

- 一言语料库本地化（独立大项，见 docs/quote-library.md）；服务器代理出口（运维）。

## 验收

- 单测：成功后失败→返回上次内容且 health ok=False；两次失败内第二次成功→ok=True 只重试一次；粘性超 7 天→离线库；英文路径同。
- 真机：健康卡在链路劣化期显示失败，画面一言不跳离线库。
