## 1. 背景与目标

v2 P1 已交付今日页分区刷新与分钟级时钟。真机使用暴露两个问题：

1. **R1 启动重影**：v2 时钟 A2 局刷直接叠加在 v1 整图（或上次会话）残留上，产生重影；随局刷次数增加逐渐消退，但开机后相当长时间观感劣化。
2. **R2 假期与日历不可见**：当前仅有今日页，月历、假期调休、黄历等 P2 规划页面缺失，用户无法回答「假期在哪」。

**目标**：
- G1：启动/进入沉浸/模式切换时先全刷清屏再绘制，重影在首屏即消除；
- G2：交付五页面集（今日/一周/月历/详情/黄历）与双模式导航（触摸优先、轮播降级），月历支持三月预裁翻月；
- G3：不破坏 v1 整图兼容与既有部署链路。

**不做**：ICS 个人日程（P3）、AQI/紫外线数据源接入（数据源暂缺，详情页用现有降水/湿度/风数据）、多城市。

## 2. 角色与场景

| 角色 | 场景 |
|------|------|
| 家庭用户 | 早晨扫一眼今日页（日期/天气/时钟）；月末想看下月假期安排 → 月历页翻月；家中长辈看黄历页宜忌 |
| 维护者 | SSH/KUAL 部署升级；浏览器打开分区 URL 验证新页面；调整轮播停留参数 |

## 3. 功能需求

### FR-1 启动清屏（P-01-01）

启动序列变更为：**全刷清屏（先纯色整屏刷新）→ 分区绘制 → 时钟绘制**。触发时机：

| 时机 | 行为 |
|------|------|
| dash.sh v2 启动 | 清屏后再绘制全部已缓存分区 |
| 进入沉浸模式（触摸模式启动） | 清屏后绘制 |
| 夜间反色切换 | 清屏（全刷）后按新色彩重绘当前页 |
| v1↔v2 模式切换 | 清屏 |

验收：启动后首屏无上一会话/v1 图残留与时钟重影；清屏操作本身允许一次正常全刷闪屏。

### FR-2 页面集（C-01~C-05）

五个页面，页序循环：today → week → month → detail → almanac。

| 页面 | 分区 | 数据依赖 | 更新节奏 |
|------|------|---------|---------|
| today 今日页 | header/clock/weather/sun/scene/quote（P1 已有） | 不变 | 时钟每分钟；其余随拉取 |
| week 一周页 | header/week-list/week-chart | daily 7 天 | 随拉取 |
| month 月历页 | header/month-title/month-grid | 历法+班休+每日农历 | 每日；**上月/当月/下月三份预裁** |
| detail 详情页 | header/hourly-trend/indices | hourly 24h | 随拉取 |
| almanac 黄历页 | header/almanac-main | 历法（宜忌/节气/物候） | 每日 |

各页共用统一页眉（页码指示 + 跳页时间戳？否——页眉含当前页指示点）。

### FR-3 页面导航（C-06）

**触摸模式**（tapread 助手可用时）：

| 手势 | 热区 | 行为 |
|------|------|------|
| 单击 | 左/右边缘竖条（宽 80px 基准） | 上一页/下一页 |
| 单击 | 月历页左下/右下角（80×80px） | 上月/下月（仅 month 页生效，轮播模式无效） |
| 单击 | 右上角（80×80px） | 手动刷新 |
| 长按 ≥2s | 右上角 | 退出沉浸，恢复系统 UI |
| 单击 | 底部中央（宽 200px） | 夜间反色开关 |

**轮播模式**（无 tapread 时默认）：按停留计划自动换页，页面循环顺序同上；触摸模式下轮播让位（触摸后 10 分钟内不轮播，之后恢复）。

参数（config.sh + env 下发默认值）：`ROTATE_ENABLED`、`ROTATE_TODAY_S`（默认 120）、`ROTATE_OTHER_S`（默认 30）、`TOUCH_ENABLED`。

### FR-4 跨月切换（C-03-03）

- 服务端同时渲染上月/当月/下月三个月历网格分区（`/r/month/grid-prev.png`、`grid-cur.png`、`grid-next.png`）与月份标题分区；
- 设备端三个月份资产全部本地缓存，翻月 = 本地切换绘制（GC16 局刷），零流量；
- 月历标题区显示当前查看月份与「回当月」方式（点今日圈注热区或再点同向角落回绕）；
- 跨天时若停留在非当月视图，回到当月。

### FR-5 服务端契约扩展（S-01-04 / S-03）

- `/api/v1/dashboard.env` 扩展：`PAGES="today week month detail almanac"`、各页分区 `R_{PAGE}_{REGION}_*` 坐标/URL/ETAG、月历三月资产、轮播参数、清屏标志；
- `/r/<page>/<region>.png` 路由从 today 专用通用化为五页；
- `/dashboard.png` 合成图扩展为**页面参数化**（`?page=week`，默认 today），v1 客户端行为不变。

### FR-6 设备端主循环扩展（P-03）

- 页面焦点状态机：`当前页 × 偏移月(month页) × 反色开关`；
- 触摸事件监听（tapread 子进程，stdout 行协议 `x y [down/up]`）；
- 轮播计时器与触摸让位逻辑；
- 拉取同步扩展到五页分区（按 ETAG 差异拉取）。

## 4. 业务规则

| 编号 | 规则 |
|------|------|
| BR-1 | 时钟每分钟 A2 局刷，禁止网络参与 |
| BR-2 | 内容分区重绘使用 GC16；启动/清屏/反色/凌晨残影治理使用全刷 |
| BR-3 | 任何绘制发生前，若处于未清屏状态（启动/模式切换），必须先全刷 |
| BR-4 | ETAG/指纹未变化的分区不重拉、不重绘 |
| BR-5 | 节假日数据缺失时不标注（不猜测） |
| BR-6 | 灰阶仅四档（0x11/0x55/0x99/0xFF），场景图 Bayer 8×8 抖动 |
| BR-7 | 触摸优先于轮播：触摸事件后 ROTATE_SUPPRESS_S（默认 600s）内不轮播 |
| BR-8 | 跨天强制回当月并全量刷新 |

## 5. 非功能需求

| 编号 | 需求 |
|------|------|
| NFR-1 | 启动到首屏 ≤ 30s（含 WiFi 唤醒；缓存齐时清屏+绘制 ≤ 5s） |
| NFR-2 | 翻页响应（触摸→重绘完成）≤ 1.5s（内容区局刷） |
| NFR-3 | 翻月切换 ≤ 0.5s（本地资产） |
| NFR-4 | 服务端分区渲染 P95 ≤ 500ms/页（首次冷渲染） |
| NFR-5 | 内存：设备端新增资产缓存 ≤ 15MB（三月月历+五页分区 PNG） |
| NFR-6 | v1 整图与旧脚本行为完全不变 |

## 6. 验收标准

1. 重启 dash.sh 与 KUAL 启动两种路径，首屏均无重影（对照 P1 现象）；
2. 五页面集可通过触摸翻页与轮播两种方式到达，页序正确；
3. 月历页显示当月农历/节气/节日/班休标注；点左下/右下角翻月，标题月份随之变化，零网络流量（飞行模式验证）；
4. 夜间反色切换后整页一致反色，无局部残留；
5. `/dashboard.png`、`/api/v1/dashboard.json`、旧 env 字段向后兼容（旧 dash.sh 仍可运行）；
6. 轮播按停留计划运行，触摸后暂停。
