| 项 | 值 |

1. 元信息：S-04，工具，code 页面。

3. 没有数据表格列。
4. 没有行内 operList。
5. 管理端表单分组、字段和按钮保持 web-admin 已有设计，本模块只换文案。
6. 没有新的详情 Card。
7. 不覆盖成列表配置页。

## 2. 动作

这些动作对应现有地址，不是新的三段 POST。

| 动作 | 方法与路径 | 谁用 |
|------|------------|------|
| 拉中文清单 | `GET /api/v1/dashboard.env` 不带 lang | 中文启动器、旧设备 |
| 拉英文清单 | `GET /api/v1/dashboard.env?lang=en` | 英文启动器 |
| 拉分区图 | `GET /r/{page}/{region}.png`，英文追加 `lang=en` | dash.sh |
| 拉整图 | `GET /dashboard.png?page={page}`，英文追加 `lang=en` | 整图回退与网页预览 |
| 打开首页 | `GET /` | 浏览器 |
| 打开管理端 | `GET /admin` | 维护者 |
| 切换语言 | 当前页 `?lang=zh` 或 `?lang=en` | 浏览器 |
| 保存配置 | 现有管理端保存接口 | 维护者。失败句子随语言 |

`GET /` 在 `format=json` 或 `Accept: application/json` 时仍返回中文接口清单，不渲染页面。

## 3. 字典

只用 enum-pool.md §3 的 `ui_lang`：`zh`、`en`。页面不另建字典接口。`page_id` 仍用已有的 today / week / month / detail / almanac，英文只改显示名。

## 4. 设备画面

### 4.1 书库

| 书名 | 文件 | 打开后 |
|------|------|--------|
| 天气台历 | `天气台历.sh` | 中文画面 |
| WeatherCalendar | `WeatherCalendar.sh` | 英文画面 |
| Weather Calendar | `Weather Calendar.sh` | 转入中文启动器，仍是中文画面 |

两本主启动器都会停掉已经在跑的台历，这是现有行为。英文入口不再自带第二套拉取循环。

### 4.2 五页英文排印

中文启动器的每个分区与现在相同。英文启动器：

| 页面 | 改为英文的界面词 | 保持中文原文 |
|------|------------------|--------------|
| 今日 | 页名 Today、星期缩写、月日、天气描述、湿度/风/降水标签、AQI 等级英文名 | 农历（前加 Lunar）、干支、节日名、一言正文 |
| 一周 | 页名 Week、星期、每天的天气描述 | 无专名翻译 |
| 月历 | 页名 Month、标题 `October 2026`、表头 Mon–Sun、休/班改为 Off/Work | 格内农历、节气、节日 |
| 详情 | 页名 Detail、湿度/风/降水/AQI 标签与等级 | 无 |
| 黄历 | 页名 Almanac、栏题 Suitable / Avoid、Solar term、Day N、Next、Phenology | 宜忌条目、节气名、物候、农历、干支 |

生肖用英文动物名。页眉仍放在现有高度内，英文用缩写。时钟区域仍只拼数字，不出现语言词。

夜间反色、左右翻页、轮播、长按退出的手势不变，只是它们所在页眉上的页名会变成英文。

### 4.3 降级（画面上能直接看出来）

英文黄历不是一本英译黄历。使用者会看到英文栏题旁边仍是中文条目，节气名也是中文。这是既定降级，不是漏译。

## 5. 网页

首页和管理端共用语言规则，不加载外部脚本或字体。现有本地样式保留。

### 5.1 语言开关

两页页头都放两个文字按钮：`中文`、`English`。当前语言那个不可再点，或标成当前项。点击后地址带上 `?lang=`，整页换成该语言，并记住一年。

没有 Cookie、地址里也没有 `lang` 时，浏览器更偏好英文则显示英文，否则中文。

`html lang`：中文 `zh-CN`，英文 `en`。

### 5.2 首页

同一模板。随语言变化的区块：标题、导语、五页按钮上的名称、三张说明卡、页内接口说明、预览等待文案、页脚。五页预览框在英文下请求带 `lang=en` 的整图，所以预览本身是英文画面。中文预览地址不追加 `lang`。

GitHub 链接地址不变。管理端入口两种语言都在，英文写成 Admin。

### 5.3 管理端

登录前、未启用、已登录三种视图都随语言变化。区块仍是：页面与轮播、城市、一言、设备状态、预览、保存、恢复默认、导出、导入。

字段、拖拽排序、今日页锁定、预览「反映已保存配置」这些交互不改。只改标签、占位符、按钮、横幅和错误句。

校验：

- 浏览器里就能发现的问题（空口令、空时区）直接显示当前语言的句子。
- 提交后服务端返回的 `code` 与现在相同，页面展示返回的 `message`。因此中文页面看到中文，英文页面看到英文。
- 限速仍是 `ADMIN_AUTH_LOCKED`。页面若要把等待秒数说成「请 N 分钟后再试」，英文用 `Try again in N minutes`。N 来自现有 `retry_after_s`，不新造规则。

城市搜索：英文页面向上游要英文地名，中文页面仍要中文地名。用户点选后保存的名字就是点中的那一行，不在保存时再翻译。

英文下的预览图使用 `lang=en`，与设备英文画面一致。

### 5.4 不在页面上出现的行为

切换语言不弹出登录，不清除已登录会话，不把配置标成未保存。导出的 JSON 不含语言字段。
