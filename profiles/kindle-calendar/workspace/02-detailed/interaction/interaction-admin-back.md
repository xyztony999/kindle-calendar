# 交互设计 PageSpec：admin-back（管理端返回首页）

| 属性 | 值 |
|------|-----|
| 模块 | admin-back |
| 版本 | v1.0 |
| 状态 | 待评审 |
| 最后更新 | 2026-10-11 |
| 输入 | api-admin-back.md v1.0 |
| 技术形态 | 在现有 `server/templates/admin.html` 页顶导航加一个链接。无新路由、无列表、无表单、无前端构建 |

## 1. 模块元信息

| 项 | 值 |
|----|-----|
| 模块编码 | P-04-03 |
| 业务类型 | 工具。页面上的一次导航 |
| 页面类型 | 在已有管理端单页上补页顶链接。无新页面 |
| 路由 | 仍是 `/admin`。点击后去 `/` |
| 响应式 | 链接在页顶一行。窄屏仍与语言链接同一行，左返回、右语言 |

确认项 1：编码 P-04-03，页面类型为现有管理端页顶，不新建路由。

## 2. Action 定义

| Action | 方法 | URL | 触发 | 对应 API |
|--------|------|-----|------|----------|
| `nav.home` | GET | `/` | 点击页顶「返回首页」 | N-2，已有首页，无新接口 |

不附带 `X-Requested-With`。这不是管理端的写操作。

确认项 4：没有 operList。唯一动作是这个链接。

## 3. 字典

不新增字典。语言仍是 enum-pool.md §3 的 `ui_lang`。

| 语言 | 链接文字 |
|------|----------|
| zh | 返回首页 |
| en | Back to home |

## 4. 页顶

`admin.html` 里现有的语言导航位于三种版面之前，本次只改这一条导航。

```
[ 返回首页 ]                    [ English 或 中文 ]
```

| 项 | 约定 |
|----|------|
| 返回链接 | 在左。文字为 `back_home`。`href="/"` |
| 语言链接 | 仍在右。中文页指向 `/admin?lang=en`，英文页指向 `/admin?lang=zh` |
| 样式 | 与现在的语言链接同一类文字链接，不用实心主按钮 |
| 可见性 | 未启用、登录、设置三种版面都显示 |

三种版面：

| 版面 | 现有内容 | 返回链接 |
|------|----------|----------|
| 未启用 | 提示设置 ADMIN_PASSWORD | 页顶可见 |
| 登录 | 口令与登录按钮 | 页顶可见 |
| 设置 | 配置、预览、退出登录 | 页顶可见。退出登录仍在设置区顶栏，两者不是同一个按钮 |

确认项 2、3、5、6：无查询条件、无表格、无表单分组、无详情 Card。

确认项 7：不改为独立的混合页或代码画布。只补这一个链接。

## 5. 点击之后

1. 浏览器打开 `/`。
2. 地址栏是网站首页。
3. 管理端会话 Cookie 还在。
4. 若设置页有未保存修改，不弹窗，配置也不写入。

## 6. 路由

| 路由 | 变化 |
|------|------|
| `/admin` | 页顶多一个链接 |
| `/` | 无变化 |

无新路由名。

## 7. 与现有页面的关系

| 页面 | 关系 |
|------|------|
| 网站首页 | 目标页。首页上进入管理端的按钮保持原样 |
| 阅读页 | 已有相同文案的返回首页。本次不改阅读页 |
| 管理端语言按钮 | 保持单按钮切换 |

## 8. 验收时要看到的行为

1. 三种版面的页顶都有返回链接，语言链接仍在右侧。
2. 中文为「返回首页」，英文为「Back to home」。
3. 点击后进入网站首页，首页页头可见。
4. 已登录用户从首页再进管理端，不需要重新登录。
5. 未保存的设置不会被这个点击写进去。
