# Gate 1 报告：editor-manage（编辑器内管理面板 + 系统积木自定义扩展）

- 日期：2026-10-24
- 启动模式：增量（基于 71337a1）
- 结论：**PASS**（用户拍板 1A + 2B）

## 需求来源

用户反馈：编辑版面时管理数据积木需退回主视图，割裂；问是否要独立路由；并希望系统积木更多自定义。

## 关键论证

- 独立路由不解决"编辑时要跳出编辑器"的本质问题，且单文件无路由架构改造成本高 → 否决。
- 选项链路已 schema 化，纯 bool 开关边际成本低（schema 1 行 + 渲染 1 个 if）→ 支持扩展包。

## 决策

| 决策点 | 选择 |
|---|---|
| 管理入口 | 1A：编辑器内嵌管理抽屉（与主视图卡片复用逻辑），主视图卡片保留 |
| 系统积木自定义 | 2B：推荐包（页眉节日行开关、天气高低温/图标开关、一言字号档位、文字对齐 UI、z 序上移/下移）+ 周起始日 + 文字字号档位 + 通用边框（除时钟）+ 修复 2 个存量 bug |

## 勘察发现（随本轮修复）

1. `grid.show_lunar` 死选项（渲染器未消费，测试断言被并行开关掩盖）。
2. `service._get_month_offset_region` 月历 ±N 月渲染漏传 options，既有 show_badges 在翻月时丢失。

## 风险

- 周起始日涉及 almanac 月矩阵缓存 key，需加维度避免脏缓存。
- 文字字号走专用字段（对齐 align 模式）而非 options 通道，避免给非系统积木开 options 校验洞。
- 通用边框对时钟无效（设备端字形拼装），schema 中明确排除 clock，避免再造死选项。
