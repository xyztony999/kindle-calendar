# 管理端反馈增量设计

日期：2026-10-16。状态：Gate 1 已由用户确认，进入实施。

## 需求与范围

维护者需要统一的品牌标识、清晰的数据积木样式选择、可理解的预览入口，以及可信的设备状态。覆盖浏览器反馈 1–5；沿用 Flask、原生 HTML/CSS/JS 与 Kindle 拉取架构。

1. Logo 使用电子阅读器轮廓结合台历装订线和信息格。黑白矢量适配墨水屏与网页明暗主题。已调用 LogoLoom 优化并导出 design/brand 品牌包；替换登录卡“历”字，并同步管理端顶栏标识。
2. 首项大字、标签加数值改为并列样式选择卡，带微型排版示例、标题和选中状态。保留原生同组 radio、键盘操作与原有 hero/rows 值；窄屏允许换行。
3. 草稿预览改名“刷新预览”，说明“自动更新 · 未保存”。修改后继续 700ms 防抖自动渲染，按钮用于立即刷新或失败重试；不保存、不下发。
4. 在线状态仅表述最近设备通信，配置下发状态独立展示。v2 已有默认 900 秒自动同步，沿用该节奏；设备请求明确标识并声明 INTERVAL，无记录为未知，超出周期两倍加 60 秒容错为离线。不能从连续手动请求间隔推算阈值。资产同步与显示成功后才确认应用版本；失败保持原确认版本。v1 整图拉取也记录通信，但不宣称应用了 v2 布局。浏览器阅读页不计设备通信。服务重启记录消失时明确显示未知，不推断离线。
5. 退出登录使用与顶栏其他操作一致的按钮外观、尺寸与对齐，保留现有退出行为。

## 验收

中文/英文、明暗主题、桌面/窄屏可用；样式选择可用键盘切换；预览不改变已保存配置；仅浏览器访问不使设备在线；设备正常自动通信无需点击下发或手动刷新；版本确认与请求配置分开；退出登录失效会话。
