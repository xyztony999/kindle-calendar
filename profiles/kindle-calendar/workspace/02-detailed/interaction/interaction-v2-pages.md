## 1. 页面结构总览

五页循环（today → week → month → detail → almanac），统一页眉页脚骨架，仅内容区随页切换。

```
┌───────────────────────────────┐ y=44
│ 页眉：日期(左) · 页指示(右)      │ 78px   每页独立资产 R_{PAGE}_HEADER
├───────────────────────────────┤ y=130
│                               │
│        内容区（随页变化）         │ 800px  R_{PAGE}_*
│                               │
├───────────────────────────────┤ y=948
│ 页脚：每日一言（跨页共享）        │ 52px   R_TODAY_QUOTE 共享资产
└───────────────────────────────┘ y=1000
（y=0-44 与 y=1000-1024 为呼吸留白，永不绘制）
```

共享分区：页脚一言资产仅一份（R_TODAY_QUOTE），week/month/detail/almanac 页布局引用相同 rect 与 URL，避免重复拉取。

## 3. 触摸热区映射（归一化，基准 758×1024）

```
┌──────────┬──────────────────────┬──────────┐
│ 刷新/退出  │                      │ 刷新/退出  │ ← y<122：右上角(x>678)=刷新，长按≥2s=退出
│  (上页)   │      内容区           │  (下页)   │ ← 122≤y<944：左右边缘竖条=翻页
│          │                      │          │
├──────────┼──────────────────────┼──────────┤
│ 翻月(仅月) │      页脚区           │ 翻月(仅月) │ ← y≥944：左下/右下角=上月/下月(仅month页)
│          │   279≤x≤479=夜间反色   │          │
└──────────┴──────────────────────┴──────────┘
```

| # | 手势 | 热区（基准坐标） | 生效页 | 动作 | 反馈 |
|---|------|----------------|--------|------|------|
| H-1 | 单击 | x<80, 122≤y<944 | 全部 | 上一页（循环） | 内容区 GC16 局刷，页眉指示更新 |
| H-2 | 单击 | x>678, 122≤y<944 | 全部 | 下一页（循环） | 同上 |
| H-3 | 单击 | x<80, y≥944 | month | 偏移月 -1（下界 -1） | title+grid 局刷，标题月份变化 |
| H-4 | 单击 | x>678, y≥944 | month | 偏移月 +1（上界 +1） | 同上 |
| H-5 | 单击 | 279≤x≤479, y≥944 | 全部 | 夜间反色开关 | 全刷一次后按新色彩重绘当前页 |
| H-6 | 单击 | x>678, y<122 | 全部 | 手动刷新 | 开网拉取 → 当前页全量重绘 |
| H-7 | 长按≥2s | x>678, y<122 | 全部 | 退出沉浸 | 恢复系统 UI |
| H-8 | D→U 1–2s | 任意 | — | 忽略（防误触缓冲） | 无 |

冲突检查：H-1/H-2 与 H-6 以 y=122 分段不重叠；H-3/H-4 与 H-5 以 x 分段（<80 / >678 vs 279–479）不重叠；H-3/H-4 仅 month 页生效，其余页该角为空操作。

## 4. 轮播时序（降级导航）

```
┌─ today(120s) ─→ week(30s) ─→ month(30s,当月) ─→ detail(30s) ─→ almanac(30s) ─┐
└──────────────────────────── 循环 ←──────────────────────────────────────────┘
触摸事件发生 → suppressed（600s 不轮播，触摸操作仍有效）→ 到期恢复 rotating，从当前页重新计时
跨天 → 偏移月复位 + 全量刷新（无论何种态）
```

参数默认值：ROTATE_TODAY_S=120、ROTATE_OTHER_S=30、ROTATE_SUPPRESS_S=600（env 下发默认，config.sh 覆盖）。

## 5. 状态与反馈规范

| 状态 | 表现 |
|------|------|
| 翻页中 | 内容区局刷（≤1.5s），页眉页脚不闪 |
| 翻月中 | title+grid 局刷（≤0.5s） |
| 刷新中 | 后续点击忽略（防抖 30s）；完成后当前页全量重绘 |
| 反色 | 全刷一次，五档灰阶整体映射反转（0x11↔0xFF, 0x55↔0x99） |
| 无网络 | 时钟照走；页眉追加「更新于 hh:mm」角标（下次成功拉取后消失） |
| 资产缺失 | 对应分区留白不绘制，日志记录，不阻塞其它分区 |
