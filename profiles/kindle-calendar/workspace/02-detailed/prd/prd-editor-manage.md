# PRD：编辑器内管理面板与系统积木自定义扩展（editor-manage）

- 版本：v1.0（2026-10-24 Gate 1 确认，用户拍板 1A + 2B）
- 前置：widget-manager 模块（71337a1）
- 范围：版面编辑器内嵌「我的积木」管理面板；系统积木自定义选项扩展（推荐包+三个中等项）；2 个存量 bug 修复

## 1. 背景

1. 上轮把积木管理迁到主视图卡片后，用户在编辑版面时仍需退出编辑器才能新建/编辑/删除数据积木，上下文切换割裂。独立路由不解决"编辑时要跳出"的本质且与单页架构冲突（Gate 1 已论证）。
2. 系统积木现有 7 个有选项，选项链路已模式化，纯开关边际成本低；用户希望更多自定义能力。
3. 勘察发现两个存量缺陷：`grid.show_lunar` 是死选项（渲染器未消费）；月历上月/下月偏移渲染漏传 options（徽标等选项丢失）。

## 2. 需求与验收

### R1 编辑器内管理面板（方案 1A）

- R1.1 弹窗左栏「管理我的积木」按钮改为在**编辑器内部**展开管理面板（覆盖左栏的抽屉，含"返回放置"关闭钮），编辑器不关闭、草稿与预览不丢。
- R1.2 抽屉内容与主视图卡片同构：数据积木列表（名称/字段摘要/编辑/删除）+ 图片素材列表（删除）+ 新建/编辑表单（名称+字段 1–6）；两处挂载复用同一套渲染与处理逻辑（参数化容器）。
- R1.3 抽屉内每行提供「放置」快捷按钮：直接把该积木放到当前画布（等同调色板点击）。
- R1.4 新建/编辑/删除即时生效：调色板放置列表与画布标签同步刷新；主视图卡片在编辑器关闭后保持一致。
- R1.5 主视图卡片保留，行为不变（兼容既有 E2E 选择器 #widget-*）。

### R2 系统积木自定义扩展（方案 2B = 推荐包 + 三个中等项）

推荐包：
- R2.1 页眉 `show_notes`（bool，默认开）：关闭时隐藏节日/假期备注（保留星期）。
- R2.2 天气 `show_range`（bool，默认开）：今日高低温行；`show_icon`（bool，默认开）：天气图标。
- R2.3 一言 `size`（choice lg/md/sm，默认 md=现状 27px 起步）：档位改起步字号，保留超宽自动收缩。
- R2.4 文字积木对齐控件（左/中/右）：align 数据链路已有，仅补外观面板 UI。
- R2.5 层级控制：选中任意积木的外观面板出现「上移一层/下移一层」，与相邻 z 交换，后端零改动。

中等项：
- R2.6 月历 `week_start`（choice mon/sun，默认 mon=现状）：表头/周末列/日期矩阵随起始日重排；month_grid_info 缓存 key 增加起始日维度；月历偏移渲染（上月/下月）同样生效。
- R2.7 文字积木 `size`（choice lg/md/sm，默认 md=现状）：走与 align 同级的专用字段（非 options 通道），字号档位改起始字号，保留自适应收缩下限。
- R2.8 通用边框 `border`（bool，默认关）：除时钟外的 12 个系统积木可加细边框（paint_system 统一绘制；时钟走设备端字形拼装，明确排除）。

修复：
- R2.9 `grid.show_lunar` 死选项：month 渲染器补消费（关闭时不再画农历节气角标）。
- R2.10 月历偏移渲染漏传 options：service 月历 offset 渲染补传块 options（连带修复既有 show_badges/新 week_start/border 在 ±N 月生效）。

### 约定

- 所有新选项默认值 = 现有版式不变；未配置 = 默认（block_options 收敛已有）。
- 前端 choice 文案：lg/md/sm 复用现有 大/中/小；mon/sun 新增 周⼀/周日 词条；choice 值→文案改为映射表而非硬编码数组。
- 不做：12/24 小时制、显示秒、时钟区日期（跨设备契约/伤屏，单独立项）。

## 3. 验收要点

- 编辑器内完成"新建→放置→保存"全程不关闭弹窗。
- 逐项关闭/切换新选项后，预览 PNG 有对应变化（像素墨量对比）；默认值与旧版渲染完全一致（回归不破）。
- week_start=sun 时月历表头从周日开始、周末高亮列正确、±1/±2 月一致。
- text size/align 保存-重登-导出导入后保持；z 序按钮在重叠积木上效果正确。
