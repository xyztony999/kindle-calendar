## 第一部分：文档概述

按用户类型列出可操作的功能项，作为交互设计与权限（多用户无，仅角色视角区分）的依据。

### 1.1 背景与目标

明确家庭用户「看什么、怎么翻」与维护者「配什么、怎么运维」的完整功能视图，支撑 P2 迭代范围。

### 1.2 文档定位

| 定位 | 说明 |
|------|------|
| 本文档做什么 | 按用户类型分章，列出每个用户可操作的功能项和功能点描述 |
| 本文档不做什么 | 不涉及技术实现方案、不涉及数据库设计、不涉及接口定义和系统架构 |

### 1.3 范围

| 范围 | 说明 |
|------|------|
| 业务域 | Kindle 电子翻页台历 |
| 用户类型 | 家庭用户、维护者 |

## 第二部分：功能清单

### 本清单概览

家庭用户覆盖核心业务域的查看与导航操作，并用书库启动器选择中文或英文画面；维护者覆盖支撑域预览验证、双语网页、基础数据域的 Web 管理端配置（页面集/轮播/一言/城市/预览/备份/设备状态）与平台支撑域设备运维。管理端为单管理员口令保护；设备侧两类用户共享同一设备，无权限隔离需求。网页语言用 Cookie 记住，不改变口令会话。
