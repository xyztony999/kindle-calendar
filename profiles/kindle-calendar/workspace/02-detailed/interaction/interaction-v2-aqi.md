## 1. 今日页 sun 分区（右半 AQI 卡）

sun 分区 (656, 788)，646×132。左半保持日出日落弧线（不变），右半原月相盘位置改 AQI 卡：

```
y 656 ┌─────────────────────────────┬──────────────────┐
      │ 日出 06:20      日落 17:45  │  AQI   45        │ ← 数值大字(40px) INK
      │        ●                    │  ──────          │
      │      ／￣￣＼   弧线+太阳点   │  良              │ ← 等级 MID(24px)
      │    ／        ＼             │  ▁▁▁▁▃▅  刻度条   │ ← 六段刻度(高8px)
      └─────────────────────────────┴──────────────────┘ y 788
                                     x ≥ 430（右半）
```

| 元素 | 规格 |
|------|------|
| AQI 标签 | 24px MID，卡片左上 |
| 数值 | 40px INK，标签右侧；失败时 `--` |
| 等级 | 22px MID，数值下方；失败时 `暂无` |
| 刻度条 | 宽 ~200px 高 8px，六段等宽（优→严重），当前段 INK 实心、其余 0xDD 空心；失败不画 |

## 2. 详情页 indices 第六卡

六卡 2×3 网格（尺寸/间距不变），第 6 卡（右下）：

| 元素 | 规格 |
|------|------|
| 标签 | `AQI`（原`月相`） |
| 值 | `{us_aqi}` 大字 + 等级文案同排（如 `45 良`）；失败 `暂无数据`（MID 22px） |

| 状态 | 表现 |
