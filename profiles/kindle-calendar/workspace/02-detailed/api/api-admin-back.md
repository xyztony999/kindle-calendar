## 1. 模块设计概述

### 1.1 业务背景及目标

维护者（用户角色）从网站首页进入管理端后，页面上没有回首页的入口（业务问题）。页顶增加一个链接，点一下打开网站首页（业务价值：不必依赖浏览器的返回）。

### 1.2 边界说明

| 边界 | 说明 |
|------|------|
| 做 | 在 `GET /admin` 的 HTML 里增加指向 `GET /` 的链接；中英文文案随管理端语言变化 |
| 不做 | 不新增 HTTP 路径；不改 `GET /` 的正文；不改 `/admin/api/*`；不改 PNG、机器 JSON、env；不改接口阅读页分流；不改登录与配置写入 |

### 1.3 设计决策

| # | 决策点 | 选择 | 理由 |
|---|--------|------|------|
| AD-0 | 混合模式 | 不适用。本模块无领域对象写入，无自管/托管数据 | 工具类，只有一次浏览器导航 |
| AD-1 | 是否新接口 | 不新增。目标是已有 `GET /` | 首页已经是网站主页 |
| AD-2 | 导航方式 | 普通链接 `href="/"` | 书签、刷新、新开管理端时，历史返回可能离开本站 |
| AD-3 | 未保存修改 | 不拦截、不自动保存 | 与现在使用浏览器返回离开的结果相同 |
| AD-4 | 会话 | 不调用退出接口 | 用户只是离开页面，回来还应是已登录 |
| AD-5 | 文案位置 | 放在 `admin_ui()`，键名 `back_home` | 管理端其余句子已在这里按语言给出 |
| AD-6 | 放置位置 | 页顶语言导航的左侧 | 该导航在三种版面之外，未启用、登录、设置都能看见 |

### 1.4 领域对象总览

| 对象 | 角色 | 说明 |
|------|------|------|
| 返回链接 | 过程数据 | 文案 + 目标 `/`。不入库 |
| 网站首页 | 关联页面 | 已有 `GET /`，本模块不定义它的字段 |
| 台历配置 | 关联领域对象 | 不读取、不写入 |

子流程：无。

### 1.5 上下文映射

| 对方 | 关系 | 说明 |
|------|------|------|
| 网站首页 | 下游页面 | 用户点击后浏览器打开 `/`。首页语言与版式保持现状 |
| 管理端登录 | 同页 | 链接不调用登录或退出 |
| 台历配置 | 无数据往来 | 点击不保存、不重置 |
| 接口阅读页 | 无数据往来 | 分流规则保持现状 |
| Kindle / 机器客户端 | 无数据往来 | 拉取路径与正文保持现状 |

## 2. 跨聚合根设计

不适用。本模块无聚合根。

## 3. 应用层约定

### 3.1 接口规范

无新路径。管理端页面仍是 `GET /admin`。返回动作是页面里的链接，浏览器随后请求已有的 `GET /`。

| 项 | 约定 |
|----|------|
| 基础路径 | 无新增。页面 `/admin`，目标 `/` |
| HTTP 方法 | 沿用现有 GET。不把这个导航改成 POST |
| 响应 | `GET /admin` 仍返回管理端 HTML；`GET /` 仍返回首页 HTML。不引入统一包装体 |
| 权限 | 链接出现在未登录和未启用的版面上，打开首页不需要管理员口令 |
| 用户类型 | 维护者可点。家庭用户无此菜单 |

### 3.2 依赖与约束

| 方向 | 对象 | 约束 |
|------|------|------|
| 依赖 | `GET /` 首页 | 只使用地址，不改首页模板 |
| 依赖 | `admin_ui(lang)` | 增加 `back_home` 文案 |
| 被依赖 | 无 | 设备、阅读页、配置保存都不依赖这个链接 |

### 3.3 权限模型

| 角色 | 说明 |
|------|------|
| 维护者 | 打开管理端并点击返回首页 |
| 未登录访客 | 若打开了 `/admin`，同样看得到链接，以便离开登录页 |
| 家庭用户 | 无此操作 |

| 操作 | 未启用 | 未登录 | 已登录 |
|------|--------|--------|--------|
| 看见返回链接 | 可以 | 可以 | 可以 |
| 打开网站首页 | 可以 | 可以 | 可以 |
| 退出登录 | 不发生 | 不发生 | 不发生 |
| 保存配置 | 不发生 | 不发生 | 不发生 |

数据权限：无新数据。

### 3.4 公共规范

| 项 | 内容 |
|----|------|
| 枚举 | 不新增。语言仍用 enum-pool.md §3 `ui_lang`（zh / en），只决定用哪句文案 |
| 错误码 | 不新增。链接没有独立的失败码 |
| 配置项 | 不新增 |

文案：

| `ui_lang` | `back_home` |
|-----------|-------------|
| zh | 返回首页 |
| en | Back to home |

## 4. 导航契约

### 4.1 领域模型

无表、无聚合根、无状态机、无领域事件。

不变量：

| # | 不变量 |
|---|--------|
| INV-1 | 三种版面的 HTML 都包含指向 `/` 的返回链接 |
| INV-2 | 链接文字只有上表两句，随当前管理端语言二选一 |
| INV-3 | 生成该链接时不写配置、不改会话 |

### 4.2 状态模型

不适用。无状态。

### 4.3 子流程

无。

### 4.4 接口设计

#### 接口清单

| 编号 | 名称 | 方法 | 路径 | 变化 |
|------|------|------|------|------|
| N-1 | 打开管理端 | GET | `/admin` | 响应 HTML 增加返回链接。状态码与登录判断不变 |
| N-2 | 打开网站首页 | GET | `/` | 无变化。作为 N-1 里链接的目标 |

无动作接口、无服务接口、无工作流回调。

#### N-1 管理端页面

请求：与现在相同，无新查询参数。

响应：`text/html`。在页顶语言导航内、语言链接之前，增加：

| 属性 | 值 |
|------|-----|
| 元素 | 链接 |
| 文字 | `back_home` |
| `href` | `/` |

业务规则：R1–R6，见 PRD 第 4 节。

校验：无输入。

#### N-2 网站首页

请求与响应保持现状。本模块不增加字段。

### 4.5 领域事件与集成

无领域事件，无消息，无仓储变更，无跨域调用。
