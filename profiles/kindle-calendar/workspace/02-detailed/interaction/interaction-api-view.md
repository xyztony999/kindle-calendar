# 交互设计：api-view（接口阅读页）

| 属性 | 值 |
|------|-----|
| 模块 | api-view |
| 版本 | v1.0 |
| 状态 | 稳定 |
| 最后更新 | 2026-10-11 |
| 设计文档 | api-api-view.md v1.0 |
| 页面类型 | code。四张 Flask 内嵌阅读页。无列表设计器、无表单、无分步单据 |

## 1. 模块元信息

| 项 | 值 |
|----|-----|
| 模块编码 | S-04-05 |
| 业务类型 | 工具。无单据状态 |
| 页面类型 | code |
| 用户 | 维护者在浏览器阅读；机器客户端不看这些页面 |

下列七项在 D0 已锁定，生成时不再追问：

1. 元信息：S-04-05，工具，code 页面。
2. 没有查询表单。`format` 与 `lang` 是地址参数，不是筛选项。
3. 逐日、逐时用阅读表，不是后台数据表格，没有列配置。
4. 没有行内 operList。
5. 没有保存表单，没有字段分组编辑。
6. 没有单据详情 Card。四个阅读页本身就是给人看的详情。
7. 不做成列表配置页，也不做成 JSON 树。

## 2. 动作

这些动作都是现有地址，不是新的三段 POST。

| 动作 | 方法与路径 | 谁用 | 看到什么 |
|------|------------|------|----------|
| 阅读台历 | `GET /api/v1/dashboard.json`，浏览器声明网页 | 维护者 | 台历阅读页 |
| 阅读天气 | `GET /weather`，浏览器声明网页 | 维护者 | 天气阅读页 |
| 阅读状态 | `GET /health`，浏览器声明网页 | 维护者 | 服务状态阅读页 |
| 阅读清单 | `GET /api/v1/dashboard.env`，浏览器声明网页 | 维护者 | 设备清单阅读页 |
| 取原文 | 同一路径 `format=json` | 维护者或机器 | 该地址今天的 JSON 或 env 文本 |
| 强制阅读页 | 同一路径 `format=html` | 测试或需要时 | 阅读页 |
| 返回首页 | `GET /` | 维护者 | 现有首页 |
| 切换语言 | 当前阅读页路径 `?lang=zh` 或 `?lang=en` | 维护者 | 整页换成另一种语言 |

首页「接口」里的链接地址保持现在的写法。不在首页上另做一套入口。

`GET /health` 被首页脚本以不声明网页的方式读取时，仍返回 JSON，首页状态行继续用现在的字段拼句子。

## 3. 字典

只用 enum-pool.md §3 的 `ui_lang`：`zh`、`en`。不新增字典，也不把 `format` 放进枚举池。

页面名沿用首页已有叫法：今日、一周、月历、详情、黄历；英文为 Today、Week、Month、Detail、Almanac。

## 4. 共用页头与页脚

四页共用一种版式，不加载外部字体或脚本。

页头：

- 站点名链到 `/`。
- 一个语言按钮。中文页写 English，链到当前路径 `?lang=en`。英文页写中文，链到 `?lang=zh`。不附带 `format`。
- 不再并排放两个语言按钮。

页脚：

- 「原始数据」链到 api-api-view.md 第 4.4.7 节规定的地址。
- 服务状态页的这条链接不带 `lang`。

浅色与当前首页的纸感相同。系统是深色时，背景、卡片和字色改为深底浅字，实心按钮用浅底深字。不出现主题开关。

窄屏下一列排开。表可以横向滚动，不把字缩到无法阅读。

来自数据的文字一律当文本显示。

## 5. 四张阅读页

### 5.1 台历数据

标题是地点名。标题下是生成时间。

区块顺序：

1. 日期：公历、星期、农历、干支与生肖、节日。有班休时显示载荷里已有的标记。本模块不另做休/班的英文对照；载荷里是什么字，页面上就显示什么字。
2. 宜与忌：两列。没有条目就写无。
3. 节气：名称、已过天数、下一节气。
4. 当前天气：温度与描述。链到天气阅读页，文案为「查看逐时」或英文 `Hour by hour`。
5. 日出与日落。月相用载荷里已有的名称，作为这一区的次要一行。
6. 空气质量：数值和等级。没有数据时写暂无 / `No data`。
7. 一言：正文和出处。
8. 页面与配置：已启用页面的显示名，以及配置版本。

不在本页放逐时大表，也不放 JSON。

### 5.2 天气

标题是城市。主视觉是当前温度和天气描述，旁边是湿度与风速。

逐日表：日期、天气、最高、最低。

逐时表：时间、温度、降水概率。行数与 JSON 里的逐时条数相同，不另做分页。

天气暂时不可用时，不显示空表，只留标题「天气暂时读不到」或英文 `Weather is unavailable`，以及返回首页。

### 5.3 服务状态

标题是「服务状态」或 `Service status`。

首先一行结论：服务在线。天气已更新时补上数据年龄；正在刷新时说明正在更新；没有天气时说明天气暂不可用。

下面逐项列出：画面尺寸、城市、配置版本、已启用页面。`last_error` 有内容时放在次要文字里，不翻译。

本页 HTTP 200，和现在的健康检查成功响应一样。

### 5.4 设备清单

标题是「设备清单」或 `Device manifest`。

摘要用定义列表，不用赋值语句当主视觉：

- 画面宽高
- 页面顺序（显示名）
- 轮播开或关
- 每个已启用页面的停留秒数
- 触摸后让位秒数
- 配置版本
- 语言：有声明则写 zh 或 en；没有则写「未声明，设备按中文」或英文 `Not set. The device uses Chinese`

分区只写地址条数，例如「分区地址 12 条」，不在摘要里铺开坐标。

摘要下面有一行说明：打开本页会计一次拉取，和管理端里的最近拉取是同一件事。

再下面是默认收起的「查看原文」/ `Show source`。展开后是等宽文本，内容与机器原文逐字相同。

### 5.5 暂时读不到

台历、天气或设备清单在数据组装失败时，阅读页只有标题和一句「暂时读不到」，加返回首页。不显示异常堆栈。状态码 500。

机器请求失败时的表现保持今天的样子，不换成这张页面。
