# 交互：editor-manage（编辑器内管理面板 / 系统积木自定义）

- 版本：v1.0（2026-10-24）

## 1. 编辑器内管理抽屉

```
版面编辑弹窗
├ 左栏（调色板列）
│  ├ 系统积木 / 我的积木 / 模板中心（现状）
│  └ [管理我的积木] ← 点击展开抽屉（覆盖左栏，z 高于调色板）
│     ├ 标题「我的积木」 [返回放置]     ← 关闭抽屉回到放置列表
│     ├ [＋ 新建数据积木]（展开表单：名称 + 字段复选 + 保存/取消）
│     ├ 积木行：名称 | 字段摘要 | ＋放置 | ✎编辑 | 🗑删除
│     ├ 图片素材
│     └ 素材行：id | 图片素材 | 用于 N 页 | 🗑删除
```

- 抽屉打开时编辑器保持开启、草稿/预览不丢；Esc 仍走"取消编辑"（弹窗级），不先关抽屉——抽屉靠「返回放置」关闭。
- 新建/编辑/删除后：抽屉列表、身后调色板、画布标签即时刷新；主视图卡片同步（同一 state）。
- 删除确认文案沿用现有；「放置」直接落画布默认位（56,160，避让时钟），与调色板点击一致。

## 2. 系统积木外观面板扩展

选中系统积木时（右栏「当前积木外观」）：
- 新选项自动出现在现有开关列表：页眉多「节日/假期备注」、天气多「今日高低温」「天气图标」、一言多「字号」单选（大/中/小）、月历多「周起始日」单选（周一/周日）、各系统积木（除时钟）多「显示边框」。
- 开关/单选操作后画布即时反馈（现有链路），未保存不影响设备。

## 3. 文字积木外观面板（新增）

选中文字积木时右栏显示：
- 「对齐」单选：左 / 中 / 右。
- 「字号」单选：大 / 中 / 小（默认中=现状）。
- 双击积木改文字的既有交互不变。

## 4. 层级控制

选中任意积木时外观面板底部出现「上移一层 / 下移一层」：
- 与 z 序相邻的积木交换层级；画布按 z 绘制，重叠时立即看到前后变化。
- 到顶/到底时按钮禁用（z 钳制 0–99）。
