## 0. 需求澄清（D0）

用户要五件事：管理端的返回和语言按钮要像现在的按钮，登录页重做；阅读页上的返回首页和原始数据同样改掉并换位置；三个传图地址在浏览器里不要直接铺开裸 PNG；管理端深色下的勾选、数字框和上下箭头要能看清；深浅色仍先跟随系统，再给一个按钮在两种外观之间切换，而且各页一致。

1. 草稿的明暗按钮在「自动 / 浅色 / 深色」三态里循环。本文按原话做成两态：没选过跟随系统，点一下只在深色和浅色之间换。
2. 草稿把管理端语言做成「中 / EN」两段。已确认的语言规则仍是一个按钮：中文页写 English，英文页写中文。
3. 草稿用 `format=raw` 强制原图。本文用 `format=png`，和阅读页用 `format=json` 要回原文的方式对齐。

### 0.1 已锁定的决策

1. 管理端顶栏，三种版面都有：左侧站点名（点了回首页），右侧依次是明暗图标按钮、语言按钮、返回首页。中文「返回首页」，英文「Back to home」。不再用紫色下划线。
2. 登录卡居中。标题仍是「Kindle 台历 · 管理端」/「Kindle Calendar · Admin」，提示、口令、登录按钮的句子不改。卡片里不再放第二条返回文字链。
3. 阅读页顶栏：左侧站点名，右侧依次是明暗、语言、原始数据、返回首页。原始数据从右上角单独的文字链，挪进这一组。没有原文可给的页（例如暂时读不到）不放原始数据按钮。
4. 图片承载页只覆盖这三个地址：`/r/<page>/<region>.png`、`/r/today/clock/<glyph>.png`、`/dashboard.png`。页顶有返回首页，以及明暗和语言。图下面有「查看原图」。不另做翻页标签或翻月按钮。
5. 只有声明要网页，或 `format=html`，才出承载页。`format=png`、`*/*`、没有 Accept、图片标签、wget、curl 仍是原来的 PNG。不看 User-Agent。
6. 明暗：没有 `kc_theme`，或值不是 `light`/`dark` 时跟随系统。按钮把当前实际外观换成另一种，并记住一年。四类页面共用这枚 Cookie：首页、管理端、阅读页、图片承载页。不提供第三下回到跟随系统。
7. 深色下管理端的复选框、文本框、数字框、数字框上下箭头、排序上下按钮、禁用行都要能看清。禁用不是把白底留在深色页面上再降低透明度。
8. 灰度图不反相。Kindle 画面、PNG 字节、ETag、机器 JSON、env、`/admin/api/*` 不改。

## 1. 背景与目标

维护者在浏览器里看到的返回、语言和原始数据仍是贴在顶上的紫色文字链；点开三张图就是一张裸图，没有返回；深色下设置页的输入框是白的，箭头发灰。系统深色已经会跟上，但没有办法自己换成另一种。

**为谁**：在浏览器里看本站的维护者。

**价值**：同一套顶栏按钮，登录页是一张清楚的卡片，图有承载页，深色下控件能读，深浅色可以自己定，而且换一页还在。

## 2. 范围

| 做 | 不做 |
|----|------|
| 管理端顶栏按钮化，登录卡重排 | 不改口令、会话、限速和配置字段 |
| 阅读页的返回首页、原始数据改成右侧按钮组 | 不改阅读页里的分块内容 |
| 三个图地址在要网页时出承载页 | 不改 PNG 像素、ETag、Cache-Control 秒数 |
| 深色下管理端控件对比 | 不改 Kindle 夜间反色 |
| 一个按钮在深色和浅色之间切换，四页记住 | 不增加「跟随系统」第三态 |
| 语言仍是一个按钮 | 不改成「中 / EN」分段 |

明确不改：`dash.sh` 与 wget/curl 拿到的 PNG、机器 JSON、env、首页 `/?format=json`、`/admin/api/*`、设备语言、书库启动器。

## 4. 行为规则

| # | 规则 |
|---|------|
| R1 | 管理端未启用、登录、设置三种版面都渲染同一条顶栏 |
| R2 | 返回首页的 `href` 是 `/`。不使用 `history.back()`，不退出登录，不提交未保存配置 |
| R3 | 语言按钮：中文页写 English，链到当前页 `lang=en`；英文页写中文，链到 `lang=zh`。仍写入现有语言 Cookie |
| R4 | 阅读页原始数据仍强制机器原文（`format=json`）。env 的原文仍是 env 文本 |
| R5 | 三个图地址：`format=html` 或 Accept 里写明的 `text/html` 优先于 JSON 时返回承载页；其余返回 PNG |
| R6 | `format=png` 即使 Accept 要网页也返回 PNG。图片标签和 Kindle 的 wget/curl 落在「其余」 |
| R7 | 承载页里的图使用 `format=png`，并带上当前网页语言。直接给设备的 PNG 仍只看地址里的设备语言，不看网页 Cookie |
| R8 | PNG 响应的正文、ETag、缓存秒数与现在相同。成功的 HTML 和 PNG 都带 `Vary: Accept`，HTML 不使用图片的 ETag |
| R9 | 打开图片承载页不记设备心跳。打开设备清单阅读页仍记，与现在相同 |
| R10 | 没有有效 `kc_theme` 时跟随 `prefers-color-scheme`。有效值只有 `light` 和 `dark` |
| R11 | 明暗按钮不提交表单。当前算出来是浅色，点击后变为深色；当前是深色，点击后变为浅色。Cookie 路径 `/`，记住一年 |
| R12 | 深色下输入框背景为深色、文字为浅色、边框亮于背景。禁用控件背景仍是深色，文字和不透明度仍能读，不把白底留在页面上 |
| R13 | 承载页和预览里的灰度图不使用反相滤镜 |
| R14 | 非法的 page、region、glyph 仍是 404。要网页时 404 可以是带返回首页的短页；不要网页时正文仍是现在的 `not found` |

## 5. 领域对象与关系

本模块不新增持久化业务对象。明暗选择只存在浏览器 Cookie。

| 对象 | 分类 | 关系 |
|------|------|------|
| 明暗选择 | 过程数据（P3） | 取值 light 或 dark。没有选择时跟随系统。四类网页一起读 |
| 图片承载页 | 过程数据（P3） | 挂在三个已有图地址上，展示已渲染的 PNG |
| 登录卡 | 过程数据（P3） | 挂在管理端登录版面，不新接口 |
| 顶栏按钮 | 过程数据（P3） | 返回、语言、明暗、原始数据、查看原图 |
| PNG 资产 | 关联对象 | 已有渲染结果。承载页只引用，不改字节 |
| 台历配置 | 关联对象 | 深色控件仍提交原来的字段 |

被引用关系：设备拉取、保存配置、心跳都不读取明暗 Cookie。其它模块不依赖承载页的 HTML。

## 6. 领域模型（D2-2）

**范围判定**：模块名 web-chrome 已标注，只增强已有网页。跳过战略设计。

| 项目 | 内容 |
|------|------|
| 本域名称 | 双语呈现（支撑）里的网页外观，加上管理端接入上的登录卡和返回按钮 |
| 领域分层 | 通用域。无单据 |
| 聚合根 | 无 |

| 对象名 | 分类 | 与上级关系 | 核心业务字段 | 关键枚举字段 | 备注 |
|--------|------|-----------|------------|------------|------|
| 明暗选择 | 过程数据 P3 | 挂在四类网页 | Cookie 值 | `ui_theme`：light / dark | 缺省不写 Cookie |
| 图片承载页 | 过程数据 P3 | 挂在三个图地址 | 图地址、返回地址 | 无 | 不入库 |

子流程：无。

| 关联领域对象 | 所属业务域 | 关联字段 | 需获取信息 | 触发关系 | 映射模式 |
|------------|-----------|---------|-----------|---------|---------|
| PNG 资产 | 页面渲染 | 路径与 page、offset、glyph | 已渲染字节 | 承载页用图片标签取出 | 遵奉者：不改像素和 ETag |
| 网站首页 | 已有网页 | 地址 `/` | 不读取字段 | 点击返回 | 遵奉者 |
| 台历配置 | 基础数据域 | 原有保存字段 | 不新增字段 | 深色只改控件外观 | 无新调用 |

| 数据项 | 类别 | 处理方式 |
|--------|------|---------|
| 是否已选明暗 | P3 | 无 Cookie 则跟随系统 |
| 所选明暗 | P2 | Cookie，不进配置文件 |
| 未保存的管理端表单 | P3 | 切换明暗或语言不提交；点返回也不提交 |

## 7. 验收

1. 管理端三种版面的顶栏都是：站点名在左，右侧为明暗、语言、返回首页。没有紫色下划线。
2. 登录卡居中，标题、提示、口令、登录仍是现有句子。卡片内没有第二条返回链接。
3. 阅读页的返回首页和原始数据在页顶右侧一组里，距视口顶边有留白。
4. 浏览器打开三个图地址看到嵌图页和返回首页。wget、curl、`Accept: */*`、`format=png` 拿到的仍是 PNG，正文与 ETag 不变。
5. 管理端预览和首页预览的图片标签仍显示图，不是一页 HTML。
6. 没选过明暗时，系统深色则页面深色，系统浅色则页面浅色。点一次换成另一种，刷新后还在；打开首页、管理端、阅读页、图片页外观相同。
7. 深色管理端里，勾选框、数字框、上下箭头、禁用的黄历行能辨认，数字框不是白底。
8. 语言仍是单按钮。保存、登录、机器 JSON、env、Kindle 拉取保持。
